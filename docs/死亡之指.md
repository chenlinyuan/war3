# 死亡之指（秒杀任意单位，含魔免）

在任意 War3 地图中通过聊天命令**秒杀当前选中的单位**，对魔法免疫单位同样生效。

## 命令

| 命令 | 说明 |
| --- | --- |
| `deathfinger` / `finger` | 秒杀当前选中的单位（对魔免也生效） |
| `deathfinger <伤害>` | 用自定义伤害秒杀（默认 1000000） |

## 使用示例

```
选中一个敌方单位 → deathfinger        → 秒杀它
deathfinger 5000                      → 用 5000 伤害秒杀（可秒掉血少的）
finger                                → 简写
```

## 原理

War3 的伤害类型决定了能否绕过魔法免疫：

| 伤害类型 | 是否绕过魔免 | 是否受护甲影响 |
| --- | --- | --- |
| `DAMAGE_TYPE_MAGIC` | 否 | 受 |
| `DAMAGE_TYPE_NORMAL` | 否 | 受 |
| `DAMAGE_TYPE_UNIVERSAL` | **是** | 否 |
| `DAMAGE_TYPE_CHAOS` | 是 | 否 |

本技能使用 **`DAMAGE_TYPE_UNIVERSAL`** + `ATTACK_TYPE_CHAOS`，因此：

- ✅ **对魔法免疫单位生效**（绕过魔免）
- ✅ **无视护甲**（不会因高护甲减伤）
- ✅ 对英雄、建筑、普通单位都有效

### 兜底逻辑

若目标因无敌/特殊状态未被击杀（仍存活），脚本会：

1. 把目标生命设为 1
2. 再补一次 UNIVERSAL 伤害

确保"秒杀"效果。

## 实现位置

| 文件 | 内容 |
| --- | --- |
| `scripts/item-browser/g.j` | `ib_fingerDamage`（默认 1000000）、`ib_fingerCount` |
| `scripts/item-browser/f.j` | `IB_FingerKill` / `IB_FingerKillUnit` / `IB_FingerMessage` |

## 调整

改 `scripts/item-browser/g.j` 中的默认伤害：

```jass
real ib_fingerDamage = 1000000.0
```

或在命令里临时指定：`deathfinger 999999`。

改完重新构建注入：

```powershell
python tools/war3map-injector/build_fj.py
python tools/war3map-injector/inject_map.py "maps/你的地图.w3x"
```

## 已知限制

- **无敌单位**：真正无敌（`SetUnitInvulnerable`）的单位无法被伤害杀死，兜底逻辑会尝试但可能仍无效。
- **目标选择**：秒杀的是**当前选中**的单位；请先选中目标。
- **多人同步**：`UnitDamageTarget` 在同步上下文调用，不会 desync。
