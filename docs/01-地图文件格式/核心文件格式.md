# 核心文件格式详解

> 本页详解最常用的几个 `war3map.*` 文件的二进制结构。
> 完整规范见 [WC3MapSpecification](https://github.com/ChiefOfGxBxL/WC3MapSpecification)。

## 通用约定

- **整数**：小端序（Little-Endian）
- **字符串**：以 `\0` 结尾的字节串（除非特别说明）
- **浮点数**：IEEE 754 单精度（4 字节）

## 1. war3map.w3i — 地图信息

### 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| FileFormat | int | 格式版本（18 = ROC, 25 = TFT, 28/31 = Reforged） |
| SaveCount | int | 保存次数 |

| GameVersionMinor | int | 游戏次版本 |

| CameraBoundsComplements | 4 × int | 边界补足 |
| PlayableWidth | int | 可玩区域宽（瓦片数） |
| PlayableHeight | int | 可玩区域高（瓦片数） |
| Flags | int | 地图标志（见下） |
| Tileset | char | 地形集（A=Ashenvale, L=Lordaeron...） |

| LoadingScreenPath | string | 载入界面模型路径 |
| LoadingScreenText | string | 载入界面文本 |
| LoadingScreenTitle | string | 载入界面标题 |
| LoadingScreenSubtitle | string | 载入界面副标题 |
| GameDataSet | int | 游戏数据版本 |
| PrologueScreenPath | string | 序章屏幕 |
| PrologueScreenText | string | 序章文本 |
| PrologueScreenTitle | string | 序章标题 |
| PrologueScreenSubtitle | string | 序章副标题 |
| FogStyle | int | 雾样式 |
| FogStartZ | float | 雾起始高度 |
| FogEndZ | float | 雾结束高度 |
| FogDensity | float | 雾密度 |
| FogColor | 4 × byte | 雾颜色 RGBA |
| WeatherId | int | 天气 ID |
| SoundEnvironment | string | 音效环境 |
| LightEnvironment | char | 光照环境（TFT） |
| WaterColor | 4 × byte | 水颜色 RGBA |
| PlayerCount | int | 玩家数 |
| Players | Player[] | 玩家数组（见下） |
| ForceCount | int | 队伍数 |
| Forces | Force[] | 队伍数组 |
| UpgradeCount | int | 升级数 |
| Upgrades | Upgrade[] | 升级数组 |
| TechCount | int | 科技数 |
| Techs | Tech[] | 科技数组 |
| RandomUnitTableCount | int | 随机单位表数 |
| RandomUnitTables | ... | 随机单位表 |
| RandomItemTableCount | int | 随机物品表数 |
| RandomItemTables | ... | 随机物品表 |

### Player 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Number | int | 玩家编号（0-based） |
| Type | int | 类型（1=人类, 2=电脑, 3=中立, 4=可营救） |
| Race | int | 种族（1=人族, 2=兽族, 3=不死, 4=暗夜, 5=恶魔, 6=其他） |
| FixedStartPosition | int | 固定起始位置 |
| Name | string | 玩家名 |
| StartLocationX | float | 起始点 X |
| StartLocationY | float | 起始点 Y |
| AllyLowPriorities | int | 低优先级盟友位掩码 |
| AllyHighPriorities | int | 高优先级盟友位掩码 |

### Force 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Flags | int | 标志（位掩码） |
| PlayerMask | int | 玩家位掩码 |
| Name | string | 队伍名 |

### 地图标志（Flags）位

| 位 | 含义 |
| --- | --- |
| 0x0001 | 隐藏地形 |
| 0x0002 | 地图已探索 |
| 0x0004 | 始终可见 |
| 0x0008 | 使用障碍 |
| 0x0010 | 观战者 |
| 0x0020 | 死亡后观战 |
| 0x0040 | 固定颜色 |
| 0x0080 | 锁定资源交易 |
| 0x0100 | 仅盟友资源交易 |
| 0x0200 | 锁定联盟变更 |
| 0x0400 | 隐藏联盟变更 |
| 0x0800 | 允许作弊码 |
| 0x1000 | 隐藏作弊码 |
| 0x2000 | 锁定游戏速度 |
| 0x4000 | 锁定随机种子 |
| 0x8000 | 共享高级控制 |
| 0x10000 | 随机英雄 |
| 0x20000 | 随机种族 |

## 2. war3map.w3e — 地形

### 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| FileFormat | char | `'W3E!'` |
| FormatVersion | int | 版本（通常 11） |
| Tileset | char | 地形集 |
| CustomTileset | int | 是否自定义地形集 |
| GroundTilesetCount | int | 地面纹理数 |
| GroundTileset | 4 × char[] | 地面纹理 ID 列表 |
| CliffTilesetCount | int | 悬崖纹理数 |
| CliffTileset | 4 × char[] | 悬崖纹理 ID 列表 |
| MapWidth | int | 宽度（瓦片数） |
| MapHeight | int | 高度（瓦片数） |
| CenterOffsetX | float | 中心偏移 X |
| CenterOffsetY | float | 中心偏移 Y |
| Tiles | Tile[width × height] | 瓦片数据 |

### Tile 结构（7 字节）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| GroundHeight | short | 地面高度（除以 4 得实际值） |
| WaterHeight | short | 水面高度（0x8000 = 无水） |
| Flags | byte | 标志 |
| GroundTexture | byte | 地面纹理索引（低 4 位） |
| CliffTexture | byte | 悬崖纹理索引（低 4 位） |
| LayerHeight | byte | 层高度（低 4 位） |

### 瓦片标志位

| 位 | 含义 |
| --- | --- |
| 0x01 | 边界 |
| 0x02 | 可通行地面 |
| 0x04 | 可建造 |
| 0x08 | 悬崖 |
| 0x10 | 水面 |
| 0x20 | 斜坡 |
| 0x40 | 可通行水面 |
| 0x80 | 荒芜之地（blight） |

## 5. 对象数据文件（w3u/w3a/w3t/w3b/w3d/w3q/w3h）

所有对象数据文件使用 **相同的结构**：

### 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| FileFormat | int | 版本（通常 2 或 3） |
| OriginalTableCount | int | 原始对象数 |
| OriginalTables | OriginalTable[] | 原始对象（修改版） |
| CustomTableCount | int | 自定义对象数 |
| CustomTables | CustomTable[] | 自定义对象 |

### OriginalTable 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| OriginalId | 4 × char | 原始对象 ID |
| NewId | 4 × char | 新对象 ID |
| ModificationCount | int | 修改数 |
| Modifications | Modification[] | 修改数组 |

### CustomTable 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| OriginalId | 4 × char | 基础对象 ID |
| NewId | 4 × char | 新对象 ID |
| ModificationCount | int | 修改数 |
| Modifications | Modification[] | 修改数组 |

### Modification 结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Id | 4 × char | 修改字段 ID（如 `'unam'` = 单位名） |
| Variation | int | 变体（技能等级等） |
| Type | int | 数据类型（见下） |
| Value | 变长 | 值（取决于 Type） |
| EndMarker | int | 结束标记（0 或 -1，版本相关） |

### 数据类型（Type）

| 值 | 类型 |
| --- | --- |
| 0 | int |
| 1 | real |
| 2 | unreal（浮点，显示为百分比） |
| 3 | string |
| 4 | bool |
| 5 | char |
| 6 | unitList（单位 ID 列表） |
| 7 | itemList |
| 8 | abilityList |
| 9 | upgradeList |
| 10 | stringList |
| 11 | abilityLevelList |
| 12 | abilityStringLevelList |
| 13 | abilityRealLevelList |

### 常用字段 ID 示例

| 字段 | 对象 | 含义 |
| --- | --- | --- |
| `unam` | 单位 | 名称 |
| `upro` | 单位 | 专有名称 |
| `uhpm` | 单位 | 最大生命 |
| `umvs` | 单位 | 移动速度 |
| `anam` | 技能 | 名称 |
| `atp1` | 技能 | 普通提示 |
| `inam` | 物品 | 名称 |
| `ides` | 物品 | 描述 |
| `gnam` | 升级 | 名称 |

## 6. war3map.wts — 字符串表

纯文本格式，存储触发器与对象数据中引用的字符串：

```
STRING 0
{
这是地图名称
}

STRING 1
{
这是地图描述
}

STRING 2
{
// 未使用的字符串
}
```

在对象数据或脚本中通过 `TRIGSTR_000` 引用（编号 = STRING 后的数字）。

### 转义规则

| 转义 | 含义 |
| --- | --- |
| `\|c` | 颜色代码开始（后跟 AARRGGBB） |
| `\|r` | 颜色代码重置 |
| `\|n` | 换行 |
| `\|t` | 制表符 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |

## 8. 解析建议

### 使用现成库

| 语言 | 库 |
| --- | --- |
| TypeScript/JS | **WC3MapTranslator** |
| C# | **War3Net** (https://github.com/Drake53/War3Net) |
| Python | **w3xparse** / 自行解析 |
| Kotlin | **Kaitai Struct** 生成 |

### 使用 WC3MapTranslator 示例

```bash
# 安装
npm install -g wc3maptranslator

# 整个目录转 JSON（便于 Git diff）
wc3maptranslator ./MyMap_unpacked --toJson

# 转回二进制
wc3maptranslator ./MyMap_json --toWar
```

```javascript
// 编程方式
import { InfoTranslator, TerrainTranslator } from 'wc3maptranslator';
import fs from 'fs';

// 读取 war3map.w3i
const buf = fs.readFileSync('war3map.w3i');
const info = InfoTranslator.warToJson(buf);
console.log(info.json.mapName);
```
