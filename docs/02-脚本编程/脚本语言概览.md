# 脚本语言概览

## 1. JASS（Just Another Scripting Syntax）

War3 的**原生脚本语言**，所有版本都支持。

### 特点

- 类 BASIC / Pascal 语法，大小写不敏感
- 静态类型，但类型检查宽松
- 函数式，无面向对象
- 支持 `native`（引擎函数）与用户函数
- 数组固定大小（`JASS_MAX_ARRAY_SIZE = 32768`）

### 文件结构

| 文件 | 说明 |
| --- | --- |
| `common.j` | 原生函数与常量定义 |
| `blizzard.j` | Blizzard 封装的 BJ 函数（GUI 生成） |
| `common.ai` | AI 脚本函数 |
| `war3map.j` | 地图脚本 |

### 语法示例

```jass
globals
    constant integer MAX_UNITS = 100
    unit array g_units
endglobals

function IsHero takes unit u returns boolean
    return IsUnitType(u, UNIT_TYPE_HERO)
endfunction

function Trig_Init_Actions takes nothing returns nothing
    local integer i = 0
    local unit u
    loop
        exitwhen i >= MAX_UNITS
        set u = CreateUnit(Player(0), 'hfoo', 0, 0, 90)
        set g_units[i] = u
        set i = i + 1
    endloop
    set u = null
endfunction
```

### JASS 的坑

- **必须手动置 `null`**：局部 `agent` 变量不置 null 会泄漏。
- **`local` 声明必须在函数开头**。
- **无 `break`/`continue`**，用 `exitwhen` 模拟。
- **数组不能动态增长**。
- **`TriggerSleepAction` 精度差**，推荐用计时器。

## 2. vJASS

JASS 的**扩展方言**，需要 **Jass NewGen Pack (JNGP)** 或 **WEX** 编译。

### 新增特性

- `struct`：结构体（类似类）
- `library` / `scope`：模块化与命名空间
- `private` / `public`：访问控制
- `static` / `method`：静态成员与方法
- `interface`：接口
- `module`：代码复用
- `textmacro`：宏
- 动态数组（`allocate` / `deallocate`）

### 语法示例

```jass
library MyLibrary initializer Init

struct Unit
    unit u
    integer id

    static method create takes player p, integer id, real x, real y returns thistype
        local thistype this = thistype.allocate()
        set this.u = CreateUnit(p, id, x, y, 90)
        set this.id = id
        return this
    endmethod

    method destroy takes nothing returns nothing
        call RemoveUnit(this.u)
        set this.u = null
        call this.deallocate()
    endmethod
endstruct

private function Init takes nothing returns nothing
    local thistype t = thistype.create(Player(0), 'hfoo', 0, 0)
    call t.destroy()
endfunction

endlibrary
```

### 注意

- vJASS 代码需编译成纯 JASS 才能被游戏运行。
- 现代项目建议直接使用 **Lua** 替代 vJASS。

## 3. Lua（Reforged 1.31+）

Reforged 引入的现代脚本语言。

### 特点

- 完整 Lua 5.3 语法
- 面向对象（table + metatable）
- 无需手动置 null（GC 管理引用）
- 性能优于 JASS（函数调用快约 40-700 倍）
- 可覆盖原生函数

### 启用方式

在地图选项中设置脚本语言为 **Lua**，生成 `war3map.lua`。

### 语法示例

```lua
-- 定义单位类
local Unit = {}
Unit.__index = Unit

function Unit.new(player, id, x, y)
    local self = setmetatable({}, Unit)
    self.handle = CreateUnit(player, id, x, y, 90)
    return self
end

function Unit:destroy()
    RemoveUnit(self.handle)
    self.handle = nil
end

-- 使用
local u = Unit.new(Player(0), FourCC("hfoo"), 0, 0)
u:destroy()
```

### 与 JASS 的差异

| 项 | JASS | Lua |
| --- | --- | --- |
| 类型 | 静态 | 动态 |
| 数组 | 固定大小 | table（动态） |
| null 处理 | 必须手动 | GC 自动 |
| 函数调用 | 慢 | 快 |
| 面向对象 | 无 | table + metatable |
| 字符串 | 单引号四字符码 | `FourCC("hfoo")` |
| 触发器 | `TriggerAddAction` | `TriggerAddAction` + 闭包 |
| 全局变量 | `globals` 块 | 直接全局（不推荐） |

### 重要注意事项

1. **Desync 风险**：`GetLocalPlayer` + 随机数 / table 遍历顺序。
2. **对象 ID**：用 `FourCC("hfoo")` 而非 `'hfoo'`。
3. **`_G` 与 `globals`**：`globals` 是游戏全局变量表。
4. **匿名函数**：避免在高频计时器中创建，可能导致 GC 压力。
5. **字符串**：`StringLength` 返回字节数（UTF-8）。

## 4. Wurst

编译到 JASS 的**现代编程语言**。

### 特点

- 强类型、编译期检查
- 现代语法（类似 Java/Kotlin）
- 优秀的 IDE 支持
- 编译产物是纯 JASS（兼容经典版）

### 语法示例

```wurst
package MyPackage

import Unit

class MyUnit
    unit u

    construct(player p, int id)
        u = CreateUnit(p, id, 0, 0, 90)

    ondestroy
        u.remove()
```

### 工具

- 官网：https://wurstlang.org/
- 仓库：https://github.com/wurstscript/WurstScript
- VS Code 扩展：WurstScript

## 5. 选择建议

| 场景 | 推荐 |
| --- | --- |
| 新项目、Reforged | **Lua** |
| 维护经典版老地图 | **JASS** |
| 需要结构体但用经典版 | **vJASS**（配 JNGP/WEX） |
| 追求工程化与类型安全 | **Wurst** |
| 快速原型、简单触发器 | **GUI（触发器编辑器）** |
