**功能**：
- 查看/编辑 MDX
- MPQ 浏览器
- 贴图管理

## 四、音频工具

| 工具 | 说明 |
| --- | --- |
| **Audacity** | 免费音频编辑 |
| **GoldWave** | 音频编辑 |
| **FFmpeg** | 命令行转换 |
| **Wav2Mp3** | WAV 转 MP3 |

### 4.1 音频转换

```bash
# FFmpeg 转换
ffmpeg -i input.wav -codec:a libmp3lame -b:a 128k output.mp3
ffmpeg -i input.mp3 output.wav
```

### 4.2 音频参数建议

| 类型 | 格式 | 参数 |
| --- | --- | --- |
| 短音效 | WAV | 22050 Hz, 16-bit, 单声道 |
| 音乐 | MP3 | 128 kbps, 44100 Hz |
