## 自定义物品支持

该地图通过 **`units\itemfunc.txt`** 定义物品（含名称），并覆盖标准物品：

- **273 个标准物品**（游戏自带）
- **115 个自定义物品**（ID 如 `I000`、`I001`、`I030` 等）
- **合计 388 项**

物品列表由 `tools/war3map-injector/collect_items.py` 从以下来源合并：

1. 游戏 `H:\Games\War3\ojzrqpjb\share\mpq\units\units\itemdata.slk`（标准物品）
2. 地图 `units\itemfunc.txt`（自定义物品 + 名称）
3. 地图 `units\itemdata.slk`（补充）

## 注入内容

**脚本**：`scripts/item-browser`（装备搜索与添加）

**新增功能**：
- `search <关键词>` — 搜索装备（支持中文）
- `additem <名称> [数量]` — 添加装备给选中英雄
- `itembrowser` — 显示帮助

**注入后大小**：1,311,415 字节（+59,445）

> ✅ **进游戏立即可用**：388 个物品 ID 预扫描硬编码，无需枚举。
> ⚠️ **脚本编码**：War3 1.27 以 GBK 解析地图脚本，`inject_map.py` 自动 UTF-8→GBK。

## 部署位置

已复制到游戏目录：`H:\Games\War3\Maps\mod\神界危机4.7_item.w3x`

## 复现步骤

```powershell
# 1. 解压地图全部文件（获取 itemfunc.txt）
python tools/war3map-injector/extract_all.py "maps/神界危机-最终正式版4.7.w3x"

# 2. 收集标准 + 自定义物品 ID
python tools/war3map-injector/collect_items.py "maps/神界危机-最终正式版4.7"

# 3. 把物品列表嵌入 f.j
python tools/war3map-injector/build_fj.py

# 4. 从原始地图重新注入
Copy-Item "神界危机-最终正式版4.7.original.w3x" "神界危机-最终正式版4.7.w3x" -Force
python tools/war3map-injector/inject_map.py "maps/神界危机-最终正式版4.7.w3x" scripts/item-browser
```
