# 资源导入

## 1. 导入方法

### 1.1 World Editor 导入

1. **模块 → 导入管理器**（Import Manager，快捷键 `F12`）。
2. 点击「导入文件」，选择资源。
3. 设置**自定义路径**（右键 → 修改文件路径）：
   ```
   war3mapImported\mymodel.mdx
   ```
   或直接使用游戏标准路径覆盖原资源：
   ```
   units\human\Footman\Footman.mdx
   ```
4. 保存地图。

### 1.2 直接编辑 MPQ

用 MPQ Editor 打开 `.w3x`，直接添加文件到对应路径。

### 1.3 编程导入（War3Net）

```csharp
var map = Map.Open("MyMap.w3x");
map.ImportedFiles.Add("war3mapImported\\mymodel.mdx", File.ReadAllBytes("mymodel.mdx"));
map.Save();
```

## 2. 路径规范

### 2.1 关键规则

- 使用 **反斜杠** `\`（不是 `/`）。
- **大小写敏感**（尤其在 Linux/Mac 或某些工具下）。
- 扩展名必须正确（`.mdx`, `.blp`, `.wav` 等）。
- 路径总长度有限制（Windows MAX_PATH = 259）。

### 2.2 覆盖游戏资源

若使用游戏标准路径，会**覆盖**原资源（全局生效）：

```
units\human\Footman\Footman.mdx      # 覆盖步兵模型
```

> ⚠️ 覆盖需谨慎，会影响所有使用该资源的单位。

### 2.3 使用自定义路径

推荐使用 `war3mapImported\` 前缀，避免冲突：

```
war3mapImported\MyFootman.mdx
```

然后在对象编辑器中引用该路径。

## 3. 模型导入

### 3.1 步骤

1. 将 `.mdx` 模型导入，路径设为 `war3mapImported\mymodel.mdx`。
2. **导入模型的所有贴图**，路径需与模型内部引用一致。
3. 在对象编辑器 → 单位 → **Art - Model File** 填入 `war3mapImported\mymodel.mdx`。
4. 测试。

### 3.2 贴图路径

模型内部引用的贴图路径必须与实际导入路径一致。用 Magos 或 Retera's Model Studio 查看/修改模型内的贴图路径。

常见问题：

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 模型显示为绿色方块 | 贴图缺失/路径错误 | 检查贴图路径 |
| 模型不显示 | 路径错误/格式错误 | 检查 MDX 格式 |
| 模型全黑 | 贴图未导入 | 导入贴图 |
| 模型无动画 | 动画名不匹配 | 检查动画名 |

### 3.3 HD/SD 模型

Reforged 支持 HD 和 SD 两套模型：

- **SD**：经典风格（`_sd.mdx` 或原版）
- **HD**：高清风格（默认）

在地图选项中设置图形模式，或提供两套模型。

## 4. 贴图导入

### 4.1 BLP 格式

War3 使用 `.blp` 贴图格式。转换工具：

| 工具 | 说明 |
| --- | --- |
| **BLP Lab** | 图形化转换 |
| **BLPConverter** | 命令行 |
| **War3 Model Editor** | 内置转换 |
| **Photoshop + BLP 插件** | 直接编辑 |

### 4.2 支持的格式

| 格式 | 说明 |
| --- | --- |
| BLP1 | 经典格式（压缩/未压缩） |
| BLP2 | 支持 DXT 压缩 |
| DDS | Reforged 支持 |
| TGA | 部分场景支持 |

### 4.3 贴图尺寸

- 建议为 **2 的幂**（64, 128, 256, 512, 1024）。
- 过大影响性能。

## 5. 图标导入

### 5.1 制作流程

1. 制作 64×64 的 TGA/BLP 图标。
2. 生成禁用版本（`DISBTN`）。
3. 转换为 BLP。
4. 导入到 `ReplaceableTextures\CommandButtons\`。

### 5.2 使用 Button Manager

自动生成所有变体（BTN/DISBTN/PASBTN/DISPASBTN）。

### 5.3 图标路径

```
ReplaceableTextures\CommandButtons\BTNMyIcon.blp
ReplaceableTextures\CommandButtonsDisabled\DISBTNMyIcon.blp
ReplaceableTextures\PassiveButtons\PASBTNMyIcon.blp
ReplaceableTextures\CommandButtonsDisabled\DISPASBTNMyIcon.blp
```

## 6. 音效导入

### 6.1 格式

| 格式 | 说明 |
| --- | --- |
| WAV | 未压缩，质量高，体积大 |
| MP3 | 压缩，体积小，适合音乐 |

### 6.2 导入步骤

1. 导入音效文件（路径如 `war3mapImported\mysound.wav`）。
2. 在**声音编辑器**（Sound Editor）中创建声音定义。
3. 在触发器中播放。

### 6.3 声音编辑器

**模块 → 声音编辑器**（F5）：

- 右键 → 新建声音
- 设置文件路径、音量、音调、3D 属性等

## 7. 资源大小优化

| 手段 | 说明 |
| --- | --- |
| 压缩贴图 | 使用 DXT 压缩 |
| 降低贴图分辨率 | 256 或 512 足够 |
| 精简模型 | 删除多余多边形/动画 |
| 音效转 MP3 | 降低码率 |
| 移除未使用资源 | 定期清理导入管理器 |
| 使用共享资源 | 多个单位共用模型/贴图 |

## 8. 常见问题

| 问题 | 解决 |
| --- | --- |
| 导入后不显示 | 检查路径大小写、扩展名 |
| 模型绿色 | 贴图路径不匹配 |
| 图标不显示 | 检查 BTN/DISBTN 命名与路径 |
| 地图体积过大 | 压缩资源、移除未使用 |
| 多人游戏资源不同步 | 确保所有资源打包进地图 |
