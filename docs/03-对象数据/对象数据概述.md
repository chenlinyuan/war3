# 对象数据概述

## 1. 数据来源

War3 的**基础游戏数据**存放在游戏 MPQ/CASC 中的 **SLK 表格文件**：

| SLK 文件 | 内容 |
| --- | --- |
| `units/unitdata.slk` | 单位基础数据 |
| `units/unitweapons.slk` | 单位武器数据 |
| `units/unitbalance.slk` | 单位平衡数据 |
| `units/unitabilities.slk` | 单位技能 |
| `units/unitfunc.slk` | 单位功能 |
| `units/unitskin.txt` | 单位皮肤 |
| `units/unitUI.slk` | 单位 UI |
| `units/AbilityData.slk` | 技能数据 |
| `units/AbilityBuffData.slk` | 增益数据 |
| `units/ItemData.slk` | 物品数据 |
| `units/UpgradeData.slk` | 升级数据 |
| `units/DestructableData.slk` | 可破坏物数据 |
| `units/Doodads.slk` | 装饰物数据 |
| `units/CampaignUnitFunc.txt` 等 | 战役数据 |

## 2. 对象数据文件

对象编辑器保存的修改存于地图内的对象数据文件：

| 文件 | 类型 | 格式版本 |
| --- | --- | --- |
| `war3map.w3u` | 单位 | 2/3 |
| `war3map.w3t` | 物品 | 2/3 |
| `war3map.w3a` | 技能 | 2/3 |
| `war3map.w3b` | 可破坏物 | 2/3 |
| `war3map.w3d` | 装饰物 | 2/3 |
| `war3map.w3q` | 升级 | 2/3 |
| `war3map.w3h` | 增益 | 2/3 |

### 2.1 结构

```
[FileFormat: int]
[OriginalTableCount: int]
  [OriginalTable...]         # 修改的原对象
[CustomTableCount: int]
  [CustomTable...]           # 新建的自定义对象
```

每个 Table：

```
[OriginalId: char[4]]        # 基础对象 ID
[NewId: char[4]]             # 修改后/新对象 ID
[ModificationCount: int]
  [Modification...]
```

每个 Modification：

```
[Id: char[4]]                # 字段 ID（如 'unam'）
[Variation: int]             # 变体（技能等级等）
[Type: int]                  # 数据类型
[Value: 变长]                # 值
[EndMarker: int]             # 结束标记
```

## 3. 数据类型（Type）

| 值 | 类型 | 说明 |
| --- | --- | --- |
| 0 | int | 整数 |
| 1 | real | 实数 |
| 2 | unreal | 实数（显示为百分比） |
| 3 | string | 字符串 |
| 4 | bool | 布尔 |
| 5 | char | 字符 |
| 6 | unitList | 单位 ID 列表 |
| 7 | itemList | 物品 ID 列表 |
| 8 | abilityList | 技能 ID 列表 |
| 9 | upgradeList | 升级 ID 列表 |
| 10 | stringList | 字符串列表 |
| 11 | abilityLevelList | 技能等级整数列表 |
| 12 | abilityStringLevelList | 技能等级字符串列表 |
| 13 | abilityRealLevelList | 技能等级实数列表 |

## 4. 字段 ID 命名规则

字段 ID 通常是 **4 个字符**，对应对象编辑器中的字段：

| 字段 ID | 对象编辑器字段 |
| --- | --- |
| `unam` | Text - Name |
| `upro` | Text - Proper Names |
| `utip` | Text - Tooltip |
| `utub` | Text - Tooltip - Extended |
| `uhpm` | Combat - Maximum Life |
| `umvs` | Movement - Speed |
| `uarm` | Combat - Armor Type |
| `udty` | Combat - Defense Type |
| `uabi` | Abilities - Normal |
| `uhab` | Abilities - Hero |
| `umdl` | Art - Model File |
| `usca` | Art - Scaling Value |
| `ushu` | Art - Shadow Image |
| `ucol` | Art - Team Color |
| `uble` | Art - Blend Time |

> 完整字段列表见游戏 `units/*.slk` 或第三方工具（如 WEX）。

## 5. 使用 War3Net 读写对象数据（C#）

```csharp
using War3Net.Build;

// 读取地图
var map = Map.Open("MyMap.w3x");

// 读取单位对象数据
var units = map.UnitObjectData;
foreach (var unit in units.Objects)
{
    Console.WriteLine($"{unit.NewId}: {unit.GetField("unam")}");
}
```

## 6. 使用 WC3MapTranslator（JS/TS）

```javascript
import { ObjectsTranslator } from 'wc3maptranslator';
import fs from 'fs';

// w3u → JSON
const buf = fs.readFileSync('war3map.w3u');
const result = ObjectsTranslator.warToJson(buf, 'unit');
console.log(JSON.stringify(result.json, null, 2));

// JSON → w3u
const back = ObjectsTranslator.jsonToWar(unitJson, 'unit');
fs.writeFileSync('war3map.w3u', back.buffer);
```
