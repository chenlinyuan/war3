# 编辑器工具

## 1. 官方 World Editor

- 随游戏自带。
- 启动：`Warcraft III.exe -editor` 或开始菜单。
- 经典版：`worldedit.exe`。

### 1.1 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `F4` | 触发器编辑器 |
| `F5` | 声音编辑器 |
| `F6` | 对象编辑器 |
| `F7` | 战役编辑器 |
| `F8` | AI 编辑器 |
| `F11` | 地形编辑器 |
| `F12` | 导入管理器 |
| `Ctrl+B` | 变量编辑器 |
| `Ctrl+F9` | 测试地图 |
| `Ctrl+S` | 保存 |

### 1.2 参数设置

**文件 → 参数设置**：

- 允许负值
- 允许自定义科技树
- 自动保存
- 显示高级工具提示

## 2. Jass NewGen Pack (JNGP)

> 经典版（≤1.27）的扩展编辑器，支持 vJASS。

### 2.1 功能

- vJASS 编译
- 扩展编辑器（Extend Editor）
- 更多对象字段
- 无地图大小限制
- 自定义 UI

### 2.2 使用

1. 下载 JNGP（Hive Workshop）。
2. 配置 War3 路径。
3. 通过 JNGP 启动 World Editor。

### 2.3 注意

- 仅支持经典版。
- 已停止维护，社区有更新分支。

## 3. WEX (Warcraft Editor eXtended)

> 现代扩展编辑器，支持 Reforged。

### 3.1 功能

- 扩展对象编辑器字段
- vJASS / Lua 支持
- 更好的 UI
- 无限制编辑

### 3.2 使用

1. 下载 WEX。
2. 配置游戏路径。
3. 启动。

## 4. Sharpcraft

> Reforged 的扩展编辑器。

### 4.1 功能

- 支持 Reforged
- 扩展字段
- 更好的对象编辑器

## 5. HiveWE

> 开源跨平台编辑器。

### 5.1 特点

- 开源（GitHub）
- 跨平台（Windows/Linux/Mac）
- 现代化界面
- 支持 Reforged

### 5.2 链接

- https://github.com/stijnherfst/HiveWE

## 6. 编辑器对比

| 工具 | 版本支持 | vJASS | Lua | 扩展字段 | 跨平台 |
| --- | --- | --- | --- | --- | --- |
| World Editor | 全版本 | ❌ | ✅(Reforged) | ❌ | ❌ |
| JNGP | ≤1.27 | ✅ | ❌ | ✅ | ❌ |
| WEX | Reforged | ✅ | ✅ | ✅ | ❌ |
| Sharpcraft | Reforged | ✅ | ✅ | ✅ | ❌ |
| HiveWE | Reforged | ❌ | ❌ | ✅ | ✅ |

## 7. 选择建议

| 场景 | 推荐 |
| --- | --- |
| 经典版 + vJASS | JNGP |
| Reforged + 扩展编辑 | WEX / Sharpcraft |
| 跨平台 | HiveWE |
| 简单项目 | 官方 World Editor |
