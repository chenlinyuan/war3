# 地图脚本注入

向任意 War3 地图（含加密地图）注入自定义 JASS 脚本。

## 一、原理

War3 地图是 MPQ 归档，脚本存于 `war3map.j`。注入即修改该文件：

```
globals
    <g.j 内容>          ← 注入全局变量
endglobals

<f.j 内容>              ← 注入函数定义

function main takes nothing returns nothing
    <m.j 内容>          ← 注入初始化调用
    ...原有代码...
endfunction
```

## 二、脚本三部分约定

| 文件 | 位置 | 用途 |
| --- | --- | --- |
| `g.j` | `globals` 块内 | 全局变量 |
| `f.j` | `main` 之前 | 函数定义 |
| `m.j` | `main` 开头 | 初始化调用 |

这是社区（HKE 工具、151 脚本集）的通用约定。

## 三、加密地图的挑战

### 3.1 官方地图的加密

Blizzard 官方对战地图（如 Lost Temple）使用**非标准加密**：

- **哈希表/块表被加密**，密钥不是标准的 `(hash table)` / `(block table)`。
- 哈希算法可能被修改，导致按文件名查找失败。
- 文件数据本身也被加密。

验证方法（Python）：

```python
import struct
raw = open('map.w3m','rb').read()
# 找 MPQ 头
idx = raw.find(b'MPQ\x1a')
# 读哈希表，检查是否有 EMPTY (0xFFFFFFFF) 标记
# 若 0 个 EMPTY 但文件数远小于表大小 → 表被加密
```

### 3.2 常规工具失效

| 工具/库 | 加密地图 |
| --- | --- |
| mpyq (Python) | ❌ 无法读表 |
| StormLib | ❌ 无法读表 |
| MPQ Editor | ⚠️ 部分支持 |
| **HkeW3mModifier2.0** | ✅ 无视已知加密 |

## 四、HkeW3mModifier 方案

### 4.1 工具能力

来自其文档：

> 一个无视已知大部分 MPQ 加密的编辑器
> 不用还原文件头即可使用
> 无视目前已知的 MPQ 头加密 可以直接修改

### 4.2 操作流程

两种注入方式：

**A. 替换 war3map.j（推荐，`inject_all.py` 默认走这条）**

1. 启动工具，**拖放**地图到窗口打开。
2. 「文件分析」→ 选中 `war3map.j` → 「解压文件」，文件会出现在**地图所在目录**。
3. 本地把 `g.j`/`f.j`/`m.j` 拼进这份 `war3map.j`。
4. 「文件选择」选 **自定义文件**，再点「添加/替换文件」选回改好的 `war3map.j`。

优点：不受 HKE 自带注入器的 `endglobals` 子串匹配 bug 影响
（YDWE 图里每个 `//endglobals from XXX` 注释都会被插一份 f.j）。

**B. HKE 自带「注入脚本」**

1. 将 `f.j`/`g.j`/`m.j` 放入 `HkeData\` 目录。
2. 拖放地图打开 → 点击 「注入脚本」 → 插件窗口 → 「注入到本图」。
3. 确认 「注入成功」。

仅适用于只有**一处** `endglobals` 的地图；且它把 g.j 插在 globals 块最前面，
地图 globals 若以 `constant` 开头需要再调一次顺序（`inject_all.py --script-mode native`
会在同一会话里顺手做完）。

**不需要点「重压缩」。** 实测替换时地图文件已经写好，重压缩 30s 内不产生任何变化
（详见 [HKE行为实测.md](HKE行为实测.md)）。

### 4.3 自动化

由于工具是 Delphi GUI 程序，自动化要点：

| 挑战 | 解决方案 |
| --- | --- |
| 文件对话框无法用消息关闭 | 用 `WM_DROPFILES` 拖放打开地图 |
| `SendMessage(BM_CLICK)` 无效 | 用 `SetCursorPos` + `mouse_event` 真实点击 |
| 点击落在错误窗口 | 点击前必须把**控件所属窗口**置前（模态对话框会被主窗口盖住） |
| 弹窗阻塞 | 枚举本进程的 `#32770`，点击「确定/是」 |
| 不要死等 | 用条件轮询（列表项数稳定 / 文件出现 / 窗口可响应）代替固定 sleep |
| 不要一次开关一次 | 会话内连续完成多个替换，最后关一次 |
| 选择列表项后解压不对 | `LB_SETCURSEL` 之后补发 `WM_COMMAND/LBN_SELCHANGE` |

参考实现：[`../../tools/war3map-injector/hke_session.py`](../../tools/war3map-injector/hke_session.py)；
一键入口 [`inject_all.py`](../../tools/war3map-injector/inject_all.py)。

```powershell
python tools/war3map-injector/inject_all.py "maps/xxx.w3x" --script `
    --file tools/war3map-injector/_hand.w3t=war3map.w3t
```

## 五、验证注入

注入后另开一次会话校验（`verify_inject.py`），它会检查标记、调用次数、
globals 顺序，以及指定文件是否逐字节一致：

```powershell
python tools/war3map-injector/verify_inject.py "maps/xxx.w3x" `
    tools/war3map-injector/_hand.w3t=war3map.w3t
```

手工方式：用工具「分析文件」→ 选中 `war3map.j` → 「解压文件」，
在**地图所在目录**找到 `war3map.j`，搜索 `IB_Init`。

## 六、纯 Python 方案（未加密地图）

对于未加密地图，可直接用 Python 修改：

```python
import sys
sys.path.insert(0, 'tools/war3map-injector')
from inject import inject_script, rebuild_map

# 读取
from war3mpq import MPQArchive
a = MPQArchive('map.w3x')
war3map_j = a.read_file('war3map.j').decode('utf-8')
a.close()

# 注入
g = open('scripts/item-browser/g.j', encoding='utf-8').read()
f = open('scripts/item-browser/f.j', encoding='utf-8').read()
m = open('scripts/item-browser/m.j', encoding='utf-8').read()
new_j = inject_script(war3map_j, g, f, m)

# 重建
rebuild_map('map.w3x', 'map_out.w3x', {'war3map.j': new_j.encode('utf-8')})
```

## 七、注意事项

1. **备份**：注入前务必备份原地图。
2. **版本兼容**：注入的脚本需匹配地图的 JASS 版本。
3. **反作弊**：部分地图有反作弊，可能阻止或检测注入。
4. **合法性**：仅用于学习与个人单机游戏，勿用于作弊或侵权。
5. **多人同步**：注入的脚本必须同步执行，避免 desync。
