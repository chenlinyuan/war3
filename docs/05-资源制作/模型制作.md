# 模型制作

## 1. 模型格式

| 格式 | 说明 |
| --- | --- |
| `.mdx` | 二进制模型格式（游戏使用） |
| `.mdl` | 文本模型格式（可编辑） |

`.mdl` 与 `.mdx` 可互相转换。

## 2. 模型结构

MDX 模型包含：

| 部分 | 说明 |
| --- | --- |
| **Geoset** | 网格（顶点、面、法线、UV） |
| **Material** | 材质（贴图、渲染层） |
| **Texture** | 贴图引用 |
| **TextureAnimation** | 贴图动画 |
| **GeosetAnimation** | 网格动画 |
| **Bone** | 骨骼 |
| **Light** | 光源 |
| **Helper** | 辅助节点（附着点） |
| **Attachment** | 附着点（特效挂载） |
| **PivotPoint** | 轴心点 |
| **ParticleEmitter** | 粒子发射器 |
| **ParticleEmitter2** | 粒子发射器 2 |
| **RibbonEmitter** | 带状发射器 |
| **EventObject** | 事件对象（音效） |
| **Camera** | 摄像机 |
| **CollisionShape** | 碰撞形状 |
| **Sequence** | 动画序列 |
| **GlobalSequence** | 全局序列 |
| **Material** | 材质 |

## 4. 从 3ds Max 导出

### 4.1 安装 NeoDex

NeoDex 是 3ds Max 的 War3 模型导出插件。

### 4.2 制作流程

1. 建模（低多边形，War3 风格）。
2. 展 UV。
3. 绑定骨骼。
4. 制作动画（命名符合 War3 规范）。
5. 用 NeoDex 导出为 `.mdx`。

### 4.3 动画命名规范

| 动画名 | 用途 |
| --- | --- |
| `Stand` | 站立 |
| `Stand - 1` / `Stand - 2` | 站立变体 |
| `Walk` | 行走 |
| `Attack` | 攻击 |
| `Attack - 1` / `Attack - 2` | 攻击变体 |
| `Death` | 死亡 |
| `Decay` | 腐烂 |
| `Dissipate` | 消散（召唤物） |
| `Birth` | 出生 |
| `Spell` | 施法 |
| `Spell Slam` | 强力施法 |
| `Spell Channel` | 引导 |
| `Portrait` | 头像 |
| `Morph` | 变身 |
| `Stand Ready` | 待命 |
| `Stand Victory` | 胜利 |
| `Stand Walk` | 站立行走 |

### 4.4 附着点命名

| 附着点 | 用途 |
| --- | --- |
| `Origin` | 原点 |
| `Overhead` | 头顶（血条上方） |
| `Head` | 头 |
| `Chest` | 胸 |
| `Hand Right` / `Hand Left` | 手 |
| `Foot Right` / `Foot Left` | 脚 |
| `Weapon` | 武器 |
| `Sprite` | 精灵 |
| `Mount` | 坐骑 |

## 5. 从 Blender 导出

### 5.1 插件

- **Blender-MDX** 插件（社区维护）
- 或先导出为 OBJ/FBX，再用工具转换

### 5.2 流程

1. 建模。
2. 展 UV。
3. 绑定骨骼与动画。
4. 导出为 `.mdl` 或 `.mdx`。

## 6. 编辑现有模型

### 6.1 用 Retera's Model Studio

1. 打开 `.mdx` 文件。
2. 编辑网格/材质/动画/附着点。
3. 导出。

### 6.2 用 Magos

1. 打开 `.mdx`。
2. **Window → MPQ Browser** 浏览游戏模型。
3. 编辑后另存。

## 7. 贴图路径

模型内部引用贴图路径。修改贴图路径：

- **Magos**：Window → Texture Manager
- **Retera's Model Studio**：Materials 面板

贴图路径必须与导入的贴图路径一致（见 [`资源导入.md`](资源导入.md)）。

## 8. 常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 模型全绿 | 贴图缺失 | 导入贴图，检查路径 |
| 模型全黑 | 材质/贴图问题 | 检查材质设置 |
| 无动画 | 动画名不匹配 | 使用标准动画名 |
| 无头像 | 缺少 Portrait 动画 | 添加 Portrait 序列 |
| 附着点特效不显示 | 附着点名称错误 | 使用标准附着点名 |
| 模型过大 | 多边形过多 | 优化网格 |
| 阴影错误 | 未设置阴影 | 检查材质阴影设置 |

## 9. 优化建议

- **低多边形**：War3 风格模型通常几百到几千面。
- **合理贴图尺寸**：256×256 或 512×512。
- **复用贴图**：多个模型共用贴图。
- **精简动画**：只保留必要动画。
- **使用 TeamColor**：通过材质实现队伍颜色。
