# 物品与升级

## 一、物品（Item）

### 1.1 物品类型

| 类型 | 说明 |
| --- | --- |
| 永久（Permanent） | 永久属性加成 |
| 充能（Charged） | 有使用次数 |
| 能量（Powerup） | 使用后消失 |
| 神器（Artifact） | 高级永久物品 |
| 可购买（Purchasable） | 商店出售 |
| 战役（Campaign） | 战役专用 |
| 杂项（Miscellaneous） | 其他 |
| 装备（Equipment） | Reforged 3.0 新增 |

### 1.2 物品对象 ID 前缀

| 前缀 | 类型 |
| --- | --- |
| `I` | 通用物品 |
| `AI` | 物品技能 |
| `p` | 能量物品（powerup） |

### 1.3 主要字段

#### 文本

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Name | `inam` | 物品名称 |
| Description | `ides` | 描述 |
| Tooltip - Basic | `itip` | 基础提示 |
| Tooltip - Extended | `iutb` | 扩展提示 |
| Hotkey | `ihot` | 热键 |

#### 属性

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Class | `icla` | 分类 |
| Level | `ilev` | 等级 |
| Gold Cost | `igol` | 金币价格 |
| Lumber Cost | `ilum` | 木材价格 |
| Hit Points | `ihtp` | 生命值 |
| Armor Type | `iarm` | 护甲类型 |
| Abilities | `iabi` | 技能列表 |
| Cooldown ID | `icid` | 冷却组 |
| Number of Charges | `iuse` | 使用次数 |
| Priority | `ipri` | 优先级 |
| Scaling Value | `isca` | 缩放值 |

#### 美术

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Art - Model | `ifil` | 模型文件 |
| Art - Icon | `iico` | 图标 |
| Art - Button Position X | `ipx1` | 按钮 X |
| Art - Button Position Y | `ipy1` | 按钮 Y |
| Art - Tinting Color (R/G/B) | `iclr`/`iclg`/`iclb` | 染色 |
| Art - Tinting Color Alpha | `ical` | 透明度 |
| Art - Team Color | `itco` | 队伍颜色 |

#### 行为

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Can Be Dropped | `idro` | 可丢弃 |
| Dropped When Carrier Dies | `idrp` | 携带者死亡掉落 |
| Perishable | `iper` | 可消失 |
| Use Automatically When Acquired | `ipow` | 获取时自动使用 |
| Can Be Sold To Merchants | `ipaw` | 可出售 |
| Actively Used | `iusa` | 主动使用 |
| Include As Random Choice | `iprn` | 随机包含 |
| Ignore Cooldown | `iicd` | 忽略冷却 |

### 1.4 脚本操作物品

```lua
-- 创建物品
local item = CreateItem(FourCC("ratf"), x, y)
local item2 = CreateItemAtLoc(FourCC("ratf"), loc)

-- 单位背包
UnitAddItem(u, item)
local newItem = UnitAddItemById(u, FourCC("ratf"))
UnitRemoveItem(u, item)
local slotItem = UnitItemInSlot(u, 0)

-- 物品属性
local charges = GetItemCharges(item)
SetItemCharges(item, 5)
local level = GetItemLevel(item)
local itemType = GetItemType(item)

-- 物品位置
SetItemPosition(item, x, y)
local ix = GetItemX(item)
local iy = GetItemY(item)

-- 物品所有权
SetItemPlayer(item, player, changeColor)
SetItemDroppable(item, true)
SetItemPawnable(item, true)
SetItemInvulnerable(item, false)
SetItemVisible(item, true)

-- 销毁
RemoveItem(item)
```

### 1.5 物品技能

物品的技能存储在 `war3map.w3a`（技能）中，通过物品字段 `iabi` 关联。

```lua
-- 获取物品技能
local abil = BlzGetItemAbility(item, FourCC("AIhe"))
local abilByIndex = BlzGetItemAbilityByIndex(item, 0)

-- 添加/移除物品技能（需物品被单位携带）
BlzItemAddAbility(item, FourCC("AIhe"))
BlzItemRemoveAbility(item, FourCC("AIhe"))
```

### 1.6 商店库存

```lua
-- 添加物品到所有商店
AddItemToAllStock(FourCC("ratf"), 1, 5)

-- 添加物品到指定商店
AddItemToStock(shop, FourCC("ratf"), 1, 5)

-- 添加单位到商店
AddUnitToAllStock(FourCC("hfoo"), 1, 1)
AddUnitToStock(shop, FourCC("hfoo"), 1, 1)

-- 移除
RemoveItemFromAllStock(FourCC("ratf"))
RemoveItemFromStock(shop, FourCC("ratf"))
```

## 二、升级（Upgrade）

### 2.1 升级类型

| 类型 | 说明 |
| --- | --- |
| 单位升级 | 提升单位属性 |
| 技能升级 | 解锁/增强技能 |
| 建筑升级 | 建筑形态变化 |

### 2.2 升级对象 ID 前缀

| 前缀 | 类型 |
| --- | --- |
| `R` | 通用升级 |
| `Rh` | 人族升级 |
| `Ro` | 兽族升级 |
| `Ru` | 不死族升级 |
| `Re` | 暗夜精灵升级 |

### 2.3 主要字段

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Name | `gnam` | 升级名称 |
| Tooltip | `gtp1` | 提示 |
| Tooltip - Extended | `gub1` | 扩展提示 |
| Icon | `gar1` | 图标 |
| Button Position X | `gbpx` | 按钮 X |
| Button Position Y | `gbpy` | 按钮 Y |
| Gold Cost | `ggol` | 金币成本 |
| Lumber Cost `glum` | 木材成本 |
| Research Time | `gtim` | 研究时间 |
| Levels | `glev` | 等级数 |
| Required Level | `grlv` | 需求等级 |
| Base Upgrade | `gbup` | 基础升级 |
| Effect - Attack Bonus | `uefa` | 攻击加成 |
| Effect - Armor Bonus | `uefa` | 护甲加成 |
| Effect - HP Bonus | `uefa` | 生命加成 |
| Race | `grac` | 种族 |
| Class | `gcls` | 分类 |

### 2.4 脚本操作升级

```lua
-- 研究升级
SetPlayerTechResearched(player, FourCC("Rhme"), 1)
AddPlayerTechResearched(player, FourCC("Rhme"), 1)

-- 查询升级等级
local level = GetPlayerTechCount(player, FourCC("Rhme"), true)
local researched = GetPlayerTechResearched(player, FourCC("Rhme"), true)

-- 降低升级等级
BlzDecPlayerTechResearched(player, FourCC("Rhme"), 1)

-- 限制最大等级
SetPlayerTechMaxAllowed(player, FourCC("Rhme"), 3)
local max = GetPlayerTechMaxAllowed(player, FourCC("Rhme"))
```

### 2.5 依赖等价物（Dependency Equivalents）

升级/单位可设置「依赖等价物」，使查询科技时把等价物也计入：

```lua
-- 查询时 specificonly = false 会计算等价物
local count = GetPlayerTechCount(player, FourCC("hhou"), false)
```

## 三、增益（Buff）

### 3.1 主要字段

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Name | `fnam` | 增益名称 |
| Tooltip | `ftip` | 提示 |
| Icon | `fart` | 图标 |
| Effect Art | `feat` | 效果模型 |
| Special Art | `fsat` | 特殊模型 |
| Target Art | `ftat` | 目标模型 |
| Buff Type | `fbty` | 类型（魔法/物理） |
| Race | `frac` | 种族 |

### 3.2 脚本操作增益

```lua
-- 移除增益
UnitRemoveBuffs(u, true, true)                       -- 移除所有增益/减益
UnitRemoveBuffsEx(u, true, true, false, false, true, false, false)

-- 查询增益
local hasBuffs = UnitHasBuffsEx(u, true, true, false, false, true, false, false)
local count = UnitCountBuffsEx(u, true, true, false, false, true, false, false)

-- 添加持续生命（定时生命）
UnitApplyTimedLife(u, FourCC("BTLF"), 30.0)
BlzUnitCancelTimedLife(u)
```

### 4.2 脚本操作可破坏物

```lua
-- 创建
local d = CreateDestructable(FourCC("LTbr"), x, y, face, scale, variation)
local dz = CreateDestructableZ(FourCC("LTbr"), x, y, z, face, scale, variation)
local dead = CreateDeadDestructable(FourCC("LTbr"), x, y, face, scale, variation)

-- 操作
KillDestructable(d)
RemoveDestructable(d)
SetDestructableLife(d, 100)
SetDestructableMaxLife(d, 200)
DestructableRestoreLife(d, 100, true)
SetDestructableInvulnerable(d, true)
ShowDestructable(d, true)

-- 查询
local life = GetDestructableLife(d)
local maxLife = GetDestructableMaxLife(d)
local typeId = GetDestructableTypeId(d)
local name = GetDestructableName(d)
```
