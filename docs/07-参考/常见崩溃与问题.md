# 常见崩溃与问题

> 参考 Hive Workshop [List of WarCraft III Crashes](https://www.hiveworkshop.com/threads/list-of-warcraft-iii-crashes.194706/)

## 一、常见崩溃原因

### 1.1 对象/句柄问题

| 原因 | 说明 |
| --- | --- |
| 使用已销毁的对象 | 访问已 `RemoveXxx` 的对象 |
| 空引用 | 对 `null` 对象调用方法 |
| 句柄溢出 | 句柄数量超过上限 |
| 无效的 FourCC | 使用不存在的对象 ID |

### 1.2 内存问题

| 原因 | 说明 |
| --- | --- |
| 内存泄漏 | 大量未销毁对象 |
| 句柄泄漏 | 未置 null 的 agent |
| 数组越界 | 访问超出范围的数组索引 |

### 1.3 脚本问题

| 原因 | 说明 |
| --- | --- |
| 无限递归 | 函数自我调用无终止 |
| 无限循环 | 循环无退出条件 |
| 除零 | 整数/实数除以 0 |
| 类型错误 | 错误的类型转换 |
| 字符串过长 | 超过字符串长度限制 |

### 1.4 触发器问题

| 原因 | 说明 |
| --- | --- |
| 销毁运行中的触发器 | 在触发器中销毁自身 |
| 销毁运行中的计时器 | 在回调中销毁计时器 |
| 递归触发 | 触发器相互触发 |
| 大量触发器 | 性能问题 |

### 1.5 资源问题

| 原因 | 说明 |
| --- | --- |
| 无效模型路径 | 引用不存在的模型 |
| 无效贴图 | 贴图缺失或格式错误 |
| 模型损坏 | MDX 文件损坏 |
| 资源过大 | 超出内存限制 |

### 1.6 多人同步

| 原因 | 说明 |
| --- | --- |
| Desync | GetLocalPlayer 误用 |
| 随机数不同步 | 异步随机 |
| table 遍历顺序 | Lua 特有 |

## 三、排查方法

### 3.1 定位崩溃

1. **查看日志**：
   ```
   Documents\Warcraft III\Errors\
   Documents\Warcraft III\Logs\War3Log.txt
   ```
2. **二分法**：注释掉一半代码，逐步缩小范围。
3. **添加调试输出**：在关键位置打印信息。
4. **最小复现**：创建最小测试地图复现问题。

### 3.2 常见排查点

| 检查项 | 方法 |
| --- | --- |
| 空引用 | 检查对象是否为 null/nil |
| 已销毁对象 | 检查 Destroy 后是否仍访问 |
| 数组越界 | 检查索引范围 |
| 无限循环 | 检查循环退出条件 |
| 递归 | 检查函数调用链 |
| 资源路径 | 检查模型/贴图路径 |

## 四、常见问题与解决

### 4.1 地图无法加载

| 问题 | 解决 |
| --- | --- |
| 地图损坏 | 用 MPQ Editor 检查/修复 |
| 版本不兼容 | 检查编辑器版本设置 |
| 资源缺失 | 检查导入资源 |
| 脚本错误 | 检查 war3map.j/lua |

### 4.2 游戏内异常

| 问题 | 解决 |
| --- | --- |
| 单位不显示 | 检查模型路径 |
| 技能无效 | 检查技能数据 |
| 触发器不触发 | 检查事件注册 |
| 文本乱码 | 检查编码（UTF-8） |
| 图标缺失 | 检查图标路径 |

### 4.3 多人问题

| 问题 | 解决 |
| --- | --- |
| Desync | 检查 GetLocalPlayer |
| 掉线 | 检查同步问题 |
| 不同步 | 检查随机数/遍历顺序 |
| 延迟 | 优化脚本性能 |

### 4.4 性能问题

| 问题 | 解决 |
| --- | --- |
| 卡顿 | 减少单位/特效数量 |
| 内存占用高 | 修复内存泄漏 |
| 加载慢 | 压缩资源 |
| 帧率低 | 优化脚本、减少触发器 |

## 五、预防措施

- [ ] 所有创建的对象都有对应销毁
- [ ] JASS 中所有局部 agent 置 null
- [ ] 不使用已销毁的对象
- [ ] 检查数组索引范围
- [ ] 避免无限循环/递归
- [ ] 检查所有资源路径
- [ ] 多人大厅测试
- [ ] 定期保存备份
