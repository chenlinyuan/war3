# 版本差异

Warcraft III 各版本功能差异对照。

## 一、版本时间线

| 版本 | 年份 | 重要变化 |
| --- | --- | --- |
| ROC 1.00 | 2002 | 混乱之治发布 |
| TFT 1.07 | 2003 | 冰封王座发布 |
| 1.13 | 2003 | 新增物品/升级字段 |
| 1.17a | 2004 | 新增攻击/伤害/武器类型 |
| 1.18a | 2005 | 新增路径类型、闪电 |
| 1.24a | 2009 | **新增哈希表** |
| 1.24b | 2009 | 类型转换修复 |
| 1.27 | 2016 | 经典版最后主要版本 |
| 1.28 | 2017 | 宽屏支持 |
| 1.29 | 2018 | 新增玩家颜色、鼠标事件、24 玩家 |
| 1.30 | 2018 | 新增动画类型、子动画 |
| 1.31 | 2019 | **新增 Lua**、Frame API、伤害事件、位运算 |
| 1.32 | 2020 | **Reforged 发布**、HD 模型、皮肤 |
| 1.33 | 2021 | 各种修复 |
| 1.35-1.36 | 2023-2024 | 持续更新 |
| 2.0 | 2024 | 新版本 |
| 3.0 | 2025 | 装备系统、新原生函数 |

## 五、图形模式

| 模式 | 说明 |
| --- | --- |

## 七、兼容性

### 7.1 向后兼容

- **Reforged 地图默认不兼容经典版**。
- 需在 `war3map.w3i` 设置较低的 **Editor Version**。
- 使用经典版不支持的功能（Lua、Frame API）会导致经典版无法运行。

### 7.2 建议

| 目标 | 编辑器版本 |
| --- | --- |
| 仅 Reforged | 最新 |
| 兼容经典版 | ≤1.27 或设置 Editor Version ≤ 6059 |
| 兼容 24 玩家 | Editor Version ≥ 6060 |
| 使用 Lua | Editor Version ≥ 6072 |

## 八、原生函数版本标注

JassDoc 中每个函数都标注了引入版本（`@patch`）：

```
@patch 1.00    # 原始版本
@patch 1.24a   # 哈希表相关
@patch 1.31.0.11889  # Lua/Frame 相关
@patch 3.0.0.24268   # 3.0 新增
```
