# 地图容器格式

> 适用：`.w3x`（TFT）、`.w3m`（ROC）、`.w3n`（战役）、`.mpq`（通用归档）

## 1. 概述

Warcraft III 地图是一个 **MPQ（Mo'PaQ）归档文件**，扩展名 `.w3x` / `.w3m`。
MPQ 是 Blizzard 的专有归档格式，也用于 `.mpq` 游戏数据文件。

```
MyMap.w3x (MPQ 容器)
├── (listfile)               # 文件清单
├── (attributes)             # 文件属性
├── war3map.w3i
├── war3map.w3e
├── war3mapUnits.doo
├── war3map.doo
├── war3map.j 或 war3map.lua
├── war3map.w3u
├── ...
└── [导入的自定义资源]
```

## 2. MPQ 文件格式

### 2.1 结构

```
┌─────────────────────────────┐
│ MPQ Header (32 bytes)       │  签名 'MPQ\x1A'
├─────────────────────────────┤
│ File Data (压缩/加密的块)    │
├─────────────────────────────┤
│ Hash Table                  │  文件名哈希 → 块索引
├─────────────────────────────┤
│ Block Table                 │  块位置/大小/标志
├─────────────────────────────┤
│ (listfile)                  │  可选：文件清单
├─────────────────────────────┤
│ (attributes)                │  可选：CRC32/文件时间
├─────────────────────────────┤
│ (signature)                 │  可选：数字签名
└─────────────────────────────┘
```

### 2.2 MPQ Header

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 4 | Magic | `'MPQ\x1A'` (0x1A51504D) |
| 0x04 | 4 | HeaderSize | 头大小（通常 32） |
| 0x08 | 4 | ArchiveSize | 归档总大小 |
| 0x0C | 2 | FormatVersion | 格式版本（0 = 原始） |
| 0x0E | 2 | BlockSize | 块大小（扇区大小 = 512 << BlockSize） |
| 0x10 | 4 | HashTablePos | 哈希表偏移 |
| 0x14 | 4 | BlockTablePos | 块表偏移 |
| 0x18 | 4 | HashTableSize | 哈希表条目数 |
| 0x1C | 4 | BlockTableSize | 块表条目数 |

### 2.3 压缩算法

MPQ 支持多种压缩（可组合）：

| 标志位 | 算法 |
| --- | --- |
| 0x02 | zlib (deflate) |
| 0x08 | PKWARE implode |
| 0x10 | bzip2 |
| 0x20 | PKWARE 稀疏压缩 |
| 0x40 | ADPCM 单声道 |
| 0x80 | ADPCM 立体声 |
| 0x01 | huffman |
| 0x12 | LZMA (Reforged/StormLib 扩展) |

### 2.4 加密

- 文件名哈希使用哈希表查找。
- 块数据可通过文件名派生密钥加密。
- `(listfile)` 列出所有文件名；加密地图会移除或加密它。

## 3. 地图容器特殊约定

### 3.1 地图头（HM3W）

`.w3x` / `.w3m` 文件开头有一个额外的地图头（用于地图选择界面）：

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 4 | Magic | `'HM3W'` (0x57334D48) |
| 0x04 | 4 | Unknown | 通常 0 |
| 0x08 | 4 | MapNameLength | 地图名长度（含 null） |
| 0x0C | N | MapName | 地图名（UTF-8） |
| ... | 4 | Flags | 标志位 |
| ... | 4 | MaxPlayers | 最大玩家数 |

> 之后才是标准 MPQ 头。Reforged 采用相同约定。

### 3.2 脚本语言标志

脚本语言（JASS / Lua）记录在 `war3map.w3i` 的 **Editor Version** 与相关字段中：

- Editor Version ≥ 6060 → 支持 24 玩家
- Editor Version ≥ 6072 → 支持 Lua 脚本

## 4. 读取工具

### 4.1 图形化

- **MPQ Editor** (Hive Workshop)
- **Ladik's MPQ Editor**
- **CascView**（Reforged CASC）

### 4.2 编程库

| 语言 | 库 |
| --- | --- |
| C/C++ | **StormLib** (https://github.com/ladislav-zezula/StormLib) |
| C# | **StormLibSharp** / **MpqToolkit** |
| Python | **mpyq** / **stormlib-py** |
| JS/TS | **WC3MapTranslator**（含 MPQ 支持） |
| Rust | **mpq** crate |

### 4.3 命令行示例（StormLib / MPQEditor）

```powershell
# 列出地图内文件
MPQEditor.exe list MyMap.w3x

# 解包全部文件
MPQEditor.exe extract MyMap.w3x * ./MyMap_unpacked

# 打包（重新构建地图）
MPQEditor.exe add MyMap.w3x ./MyMap_unpacked\* /r
```

## 5. 加密地图

部分作者会加密地图防止修改：

| 手段 | 说明 | 破解难度 |
| --- | --- | --- |
| 移除 `(listfile)` | 无法列出文件名 | 低（可用已知文件名扫描） |
| 加密 `war3map.j` | 脚本被加密 | 中（需密钥） |
| 删除 `war3map.wtg` | 无法恢复 GUI 触发器 | 低（仍有 .j） |
| 混淆脚本变量名 | 可读性差 | 低 |
| 自定义 MPQ 变体 | 非标准格式 | 高 |

> **注意**：破解他人加密地图可能违反作者意愿与社区规范，请仅用于学习分析。

## 6. 版本差异

| 版本 | 存储 | 说明 |
| --- | --- | --- |
| ROC / TFT ≤ 1.27 | MPQ | 经典 |
| Reforged 1.32+ | MPQ（地图仍是 MPQ） | 游戏数据改为 CASC |
| Reforged 2.0+ | MPQ | 地图格式基本不变 |

> 地图文件本身始终是 MPQ；只有游戏资源（模型/贴图基础库）从 MPQ 迁移到 CASC。
