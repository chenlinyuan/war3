# 单位数据

单位对象编辑器字段详解。

## 1. 单位类型

| 类型 | 说明 |
| --- | --- |
| 普通单位 | 可训练/建造的单位 |
| 英雄 | 有等级、属性、技能的英雄 |
| 建筑 | 不可移动的建筑物 |
| 中立 | 野怪、商店等 |

## 4. 脚本中操作单位属性

Lua 中可通过 `Blz*` 函数在运行时修改单位字段：

```lua
-- 获取/设置最大生命
local maxHp = BlzGetUnitMaxHP(u)
BlzSetUnitMaxHP(u, 500)

-- 获取/设置最大魔法
local maxMp = BlzGetUnitMaxMana(u)
BlzSetUnitMaxMana(u, 300)

-- 获取/设置基础伤害
local dmg = BlzGetUnitBaseDamage(u, 0)  -- 武器索引 0
BlzSetUnitBaseDamage(u, 50, 0)

-- 获取/设置护甲
local armor = BlzGetUnitArmor(u)
BlzSetUnitArmor(u, 10.0)

-- 获取/设置单位字段
BlzSetUnitIntegerField(u, UNIT_IF_AGILITY, 20)
BlzSetUnitRealField(u, UNIT_RF_SIGHT_RADIUS, 1000.0)
BlzSetUnitStringField(u, UNIT_SF_NAME, "新名字")

-- 获取/设置武器字段
BlzSetUnitWeaponRealField(u, UNIT_WEAPON_RF_ATTACK_RANGE, 0, 500.0)
```

> 注意：部分字段设置无效或返回假阳性，详见 JassDoc 注解。
