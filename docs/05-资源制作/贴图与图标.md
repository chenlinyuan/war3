# 贴图与图标

## 一、贴图（Texture）

### 1.1 BLP 格式

War3 使用 `.blp` 贴图格式。

| 版本 | 说明 |
| --- | --- |
| BLP1 | 经典格式，支持 JPEG 压缩 |
| BLP2 | 支持 DXT1/DXT3/DXT5 压缩、调色板 |

### 1.2 转换工具

| 工具 | 说明 |
| --- | --- |
| **BLP Lab** | 图形化，推荐 |
| **BLPConverter** | 命令行批量转换 |
| **War3 Model Editor** | 内置转换 |
| **Photoshop + BLP 插件** | 直接编辑 BLP |
| **GIMP + 插件** | 免费方案 |

### 1.3 支持的源格式

| 格式 | 说明 |
| --- | --- |
| TGA | 无损，支持 Alpha |
| PNG | 无损，支持 Alpha |
| JPG | 有损，不支持 Alpha |
| DDS | Reforged 支持 |
| BMP | 无 Alpha |

### 1.4 制作流程

1. 在图像软件中制作贴图（建议 2 的幂尺寸）。
2. 导出为 TGA/PNG。
3. 转换为 BLP。
4. 导入地图。

### 1.5 尺寸建议

| 用途 | 建议尺寸 |
| --- | --- |
| 单位贴图 | 256×256 或 512×512 |
| 建筑贴图 | 256×256 |
| 特效贴图 | 64×64 或 128×128 |
| 图标 | 64×64 |
| UI 元素 | 视情况 |

### 1.6 Alpha 通道

- 使用 TGA（32 位）或 PNG 保留 Alpha。
- 透明部分在游戏中显示为透明。

### 1.7 队伍颜色（Team Color）

War3 通过**特定区域**实现队伍颜色：

- 贴图中使用特定颜色区域（通常为纯红/纯蓝）。
- 材质设置 `TeamColor` 或 `TeamGlow` 渲染模式。
- 游戏运行时替换为玩家颜色。

## 二、图标（Icon）

### 2.1 图标类型

| 类型 | 前缀 | 用途 |
| --- | --- | --- |
| 普通按钮 | `BTN` | 主动技能/单位 |
| 禁用按钮 | `DISBTN` | 不可用时 |
| 被动按钮 | `PASBTN` | 被动技能 |
| 禁用被动 | `DISPASBTN` | 被动不可用 |
| 攻击类型 | `ATC` | 攻击类型图标 |
| 升级 | `UPG` | 升级图标 |
| 信息卡 | `INFOCARD` | 单位信息卡 |

### 2.2 图标尺寸

- 标准：**64×64**
- 部分 UI：**48×48** 或 **32×32**

### 2.3 图标边框

War3 图标有标准边框样式：

- 普通图标：金色/银色边框
- 被动图标：绿色边框
- 禁用图标：灰暗

### 2.4 制作流程

1. 制作 64×64 图标。
2. 添加边框（可选，游戏会叠加）。
3. 生成禁用版本（降低亮度/饱和度）。
4. 转换为 BLP。
5. 导入到对应路径。

### 2.5 使用 Button Manager

Button Manager 可自动生成所有变体：

1. 输入普通图标。
2. 自动生成 `DISBTN`、`PASBTN`、`DISPASBTN`。
3. 批量导出为 BLP。

### 2.6 图标路径

```
ReplaceableTextures\CommandButtons\BTNMyIcon.blp
ReplaceableTextures\CommandButtonsDisabled\DISBTNMyIcon.blp
ReplaceableTextures\PassiveButtons\PASBTNMyIcon.blp
ReplaceableTextures\CommandButtonsDisabled\DISPASBTNMyIcon.blp
```

### 2.7 在对象编辑器中引用

- 单位/技能/物品的 **Art - Icon - Game Interface** 字段填入图标路径。
- 只需填 `BTN` 版本，游戏自动查找 `DISBTN` 等变体。

## 三、UI 贴图

### 3.1 UI 资源路径

| 路径 | 用途 |
| --- | --- |
| `UI\Console\` | 控制台界面 |
| `UI\Widgets\` | 控件 |
| `UI\FrameDef\` | 框架定义 |
| `UI\Glues\` | 菜单界面 |
| `UI\SoundInfo\` | 声音信息 |

### 3.2 自定义 UI

通过 `.fdf`（框架定义文件）和 `.toc`（表目录）自定义 UI：

```
UI\FrameDef\MyUI.fdf
UI\MyUI.toc
```

### 3.3 框架定义（FDF）

FDF 是文本格式，定义 UI 框架：

```
Frame "BACKDROP" "MyBackdrop" {
    BackdropBlendAll,
    Texture "MyTexture.blp",
    ...
}
```

### 3.4 加载 TOC

```lua
BlzLoadTOCFile("war3mapImported\\MyUI.toc")
```

## 四、常见问题

| 问题 | 解决 |
| --- | --- |
| 贴图显示为绿色 | 检查 BLP 格式、路径 |
| 贴图透明部分变黑 | 检查 Alpha 通道 |
| 图标不显示 | 检查路径、命名 |
| 图标模糊 | 使用 64×64，避免拉伸 |
| 队伍颜色错误 | 检查材料渲染模式 |
