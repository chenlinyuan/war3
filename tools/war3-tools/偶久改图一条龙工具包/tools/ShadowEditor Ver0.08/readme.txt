ShadowEditor V0.08
制作:RahXephon

V0.08功能:
识别签名地图.
修复某些加密器对地图MPQ的文件头的修改,修复后此类地图可以用MPQMASTER打开.
listfile重建功能,可以在没有内部listfile的情况下显示大部分地图资源.
MPQ文件基本操作(与MPQMASTER等MPQ工具一样).
可编辑地图文件头中定义的地图名称(此名称显示在游戏地图列表中).
可编辑W3I地图基本信息文件(小地图上名称,及LOADING画面等的文字信息)
可编辑WTS地图文本文件
可重建IMP文件导入列表文件
可自定义MPQ文件上限及BUFFER SIZE进行重压缩(要求有完整listfile)

注意:	某些地图可能无法导入列表文件,出现此情况请导出生成的列表,并在设置中设置该列表为默认列表,
	再次读取地图即可列出所有资源.
	
	对于某些地图可能出现文件头修复后实际文件数有小数的情况,这时只要重压缩就能自动恢复正常,
	本工具对于未修复文件头的地图依然可以进行修改,因此不必考虑修复是否完全(不用再费力去用UE做还原,
	除非游戏不能读取),即不存在所谓的无法解密问题.
修正:
07/09/2007:
V0.08:	增加新建MPQ文件的功能

	增加重建war3map.imp文件的功能,解决使用本工具添加文件后,WE不能显示所导入文件的问题.
	
	增加自定义BUFFER SIZE进行重压缩的功能,较大的BUFFER SIZE可以使压缩后的地图文件体积减小,
	但地图文件的BUFFER SIZE不应超过4096KB的上限.重压缩一律使用ZLIB压缩,压缩效果较好,但要求有
	完整的listfile,否则会造成文件丢失.

	修正打开非地图MPQ文件时出错的问题,现在可以正常打开所有MPQ文件
	
	更改了替换文件的过程,修正替换文件可能造成的体积变大问题
	
	修正地图缺少W3I,WTS等文件时,相应编辑出错的问题

	修正部分快捷键冲突问题

	修正若干小BUG
