# 环境搭建

> 适用：Warcraft III Reforged 1.32+ / 2.0 / 3.0，及经典版 1.27 / 1.28

## 1. 游戏本体

### 1.1 官方渠道（推荐）

- **Battle.net 客户端**：购买 / 免费下载 Warcraft III: Reforged。
  - 安装路径通常为 `C:\Program Files (x86)\Warcraft III\_retail_`
  - PTR 测试服为 `_ptr_`
- **经典版**：可通过 Blizzard 的 legacy 下载器获取 1.27b 等版本（社区镜像）。

### 1.2 关键目录

```
Warcraft III/
├── _retail_/              # 正式版
│   ├── Warcraft III.exe
│   ├── war3.mpq           # 基础游戏数据
│   ├── war3x.mpq          # 冰封王座数据
│   ├── war3patch.mpq      # 补丁数据
│   ├── War3xLocal.mpq     # 本地化数据
│   └── Maps/              # 官方地图
├── _ptr_/                 # 测试服
└── x86_64/                # Reforged 64 位客户端
```

> **Reforged 1.32+** 使用 **CASC** 存储（`Data/` 目录），不再是 MPQ。经典版仍是 MPQ。

## 2. World Editor（世界编辑器）

- 随游戏自带：`Warcraft III.exe -editor` 或开始菜单快捷方式。
- 经典版编辑器：`worldedit.exe`（在游戏根目录）。

### 2.1 启用高级功能

- **文件 → 参数设置**：
  - 勾选「允许负值」「允许自定义科技树」等。
- **扩展编辑器**（Extend Editor）：需要第三方工具（见下）。

## 4. VS Code Lua 开发环境配置

### 4.1 安装扩展

```
Lua (sumneko.lua)          # Lua 语言服务器
Dencer.warcraft-vscode     # War3 集成（可选）
```

### 4.2 获取 API 定义文件

从 Hive Workshop 的
[《A comprehensive guide to Mapping in Lua》](https://www.hiveworkshop.com/threads/a-comprehensive-guide-to-mapping-in-lua.341880/)
下载：

- `common.lua` — 原生函数定义
- `blizzard.lua` — BJ 函数定义
- `CommonAI.lua` — AI 函数定义
- `HiddenNatives.lua` — 隐藏原生函数

或从游戏导出：World Editor → 文件 → 导出脚本（Export Script）。

### 4.3 推荐的 `settings.json`

```json
{
    "Lua.runtime.version": "Lua 5.3",
    "Lua.workspace.preloadFileSize": 2000,
    "Lua.workspace.maxPreload": 1000,
    "Lua.hint.enable": true,
    "Lua.type.weakUnionCheck": true,
    "Lua.type.weakNilCheck": true,
    "Lua.diagnostics.disable": [
        "lowercase-global",
        "inject-field"
    ],
    "editor.parameterHints.enabled": true,
    "editor.semanticHighlighting.enabled": true
}
```

## 5. 验证安装

1. 打开 World Editor，新建地图，放置一个单位。
2. 保存为 `test.w3x`。
3. 用 MPQ Editor 打开，确认能看到 `war3map.j` / `war3map.lua`。
4. 在游戏中测试运行地图。

## 常见问题

| 问题 | 解决 |
| --- | --- |
| 编辑器打不开地图 | 检查地图是否被加密/损坏，尝试用 MPQ Editor 修复 |
| Lua 模式不生效 | 需在「情节 → 地图选项」或 `war3map.w3i` 中设置脚本语言为 Lua |
| 导入模型不显示 | 检查路径大小写、贴图路径、是否为 HD/SD 模型 |
| 地图在经典版崩溃 | Reforged 地图默认不兼容，需降低编辑器版本 |
