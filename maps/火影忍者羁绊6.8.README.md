# 火影忍者羁绊 6.8 · 改图工程

在 RPG 地图 **火影忍者羁绊6.8** 上注入装备搜索/添加系统。

| 文件 | 说明 |
| --- | --- |
| `火影忍者羁绊6.8.original.w3x` | 原始地图备份（未修改） |
| `火影忍者羁绊6.8.w3x` | **已注入脚本**的地图（可游玩） |

| 项 | 值 |

## 物品统计

- **可创建物品：476 个**
  - 原版物品：57 个
  - 自定义物品：419 个（如火影主题：金币、修炼之书、查克拉药水、[中忍]护靴…）

物品列表由 `collect_items.py` 以地图 `units\itemdata.slk` 为准生成。

## 注入内容

**脚本**：`scripts/item-browser`（装备搜索与添加）

**新增功能**：
- `search <关键词>` — 搜索装备（原版/自定义分开显示，带物品 ID）
- `additem <名称> [数量]` — 添加装备
- `additem <物品ID>` — 按 ID 添加（区分同名）
- `itembrowser` — 显示帮助

**注入后大小**：32,377,984 字节（+3,994，地图高度压缩）

> ✅ 进游戏立即可用（476 个物品预扫描硬编码，无需枚举）
> ✅ 脚本以 UTF-8 注入（War3 按 UTF-8 读取字符串字面量）

## 部署位置

已复制到游戏目录：`H:\Games\War3\Maps\mod\火影忍者羁绊6.8_item.w3x`

## 复现步骤

```powershell
# 1. 解压地图全部文件（获取 itemdata.slk / itemfunc.txt）
python tools/war3map-injector/extract_all.py "maps/火影忍者羁绊6.8.original.w3x"

# 2. 收集物品 ID 与名称
python tools/war3map-injector/collect_items.py "maps/火影忍者羁绊6.8.original"

# 3. 把物品列表嵌入 f.j
python tools/war3map-injector/build_fj.py

# 4. 从原始地图重新注入
Copy-Item "火影忍者羁绊6.8.original.w3x" "火影忍者羁绊6.8.w3x" -Force
python tools/war3map-injector/inject_map.py "maps/火影忍者羁绊6.8.w3x" scripts/item-browser

# 5. 部署到游戏 mod 目录（自动清理旧版本）
python tools/war3map-injector/deploy_mod.py "maps/火影忍者羁绊6.8.w3x" "火影忍者羁绊6.8_item.w3x"
```
