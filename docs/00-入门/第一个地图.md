# 第一个地图

> 目标：从零创建一张可运行的自定义地图，理解基本工作流。

## 1. 新建地图

1. 打开 **World Editor**。
2. 菜单 **文件 → 新建地图**。
3. 设置：
   - **地图大小**：64×64（小图便于测试）
   - **地形纹理集**：Ashenvale / Lordaeron Summer 等
   - **初始水域**：无
4. 点击确定。

## 2. 绘制地形

- **地形面板**（快捷键 `T`）：
  - 应用高度 / 纹理 / 悬崖 / 水
- **装饰物面板**（快捷键 `D`）：放置树木、岩石、建筑
- **单位面板**（快捷键 `U`）：放置单位

### 常用技巧

| 操作 | 快捷键 |
| --- | --- |
| 提高地形 | `+` |
| 降低地形 | `-` |
| 平滑地形 | `S` |
| 切换网格 | `G` |
| 显示路径阻断 | `P` |

## 3. 设置玩家与初始点

1. **情节 → 玩家属性**：设置玩家数量、种族、队伍。
2. **单位面板 → 起始点**：为每个玩家放置起始点（Start Location）。

## 4. 添加触发器

1. 打开 **触发器编辑器**（快捷键 `F4`）。
2. 新建触发器，例如「游戏开始时显示提示」：

```
事件:  Map Initialization
条件:  (无)
动作:  游戏 - 显示文本给 (所有玩家): "欢迎来到我的地图！"
```

### 对应的 JASS 代码

```jass
function Trig_Melee_Initialization_Actions takes nothing returns nothing
    call DisplayTextToPlayer(GetLocalPlayer(), 0, 0, "欢迎来到我的地图！")
endfunction

//===========================================================================
function InitTrig_Melee_Initialization takes nothing returns nothing
    set gg_trg_Melee_Initialization = CreateTrigger()
    call TriggerAddAction(gg_trg_Melee_Initialization, function Trig_Melee_Initialization_Actions)
endfunction
```

### 对应的 Lua 代码

```lua
function InitTrig_Melee_Initialization()
    local t = CreateTrigger()
    TriggerAddAction(t, function()
        DisplayTextToPlayer(GetLocalPlayer(), 0, 0, "欢迎来到我的地图！")
    end)
end
```

## 5. 切换脚本语言为 Lua（可选）

1. **情节 → 地图选项**（或菜单中的地图描述）。
2. 勾选 / 设置 **脚本语言 = Lua**。
3. 保存后，地图内将生成 `war3map.lua` 而非 `war3map.j`。

> 也可通过编辑 `war3map.w3i` 的脚本语言字段实现。

## 6. 测试地图

- **Ctrl + F9**：在游戏中测试当前地图。
- 或 **文件 → 测试地图**。

## 7. 保存与发布

1. **文件 → 保存**，得到 `MyMap.w3x`。
2. 地图默认存放在：
   ```
   Documents\Warcraft III\Maps\
   ```
3. 发布前建议：
   - 用 MPQ Editor 检查导入资源路径。
   - 移除调试代码。
   - 在多人大厅测试同步（防 desync）。

## 8. 解包地图（用于版本管理与 diff）

```powershell
# 使用 MPQ Editor 或 StormLib 解包
# 也可用 WC3MapTranslator 将 war3map.* 转为 JSON
npm install -g wc3maptranslator
wc3maptranslator ./MyMap_unpacked --toJson
```

解包后的目录结构：

```
MyMap/
├── war3map.w3i          # 地图信息
├── war3map.w3e          # 地形
├── war3mapUnits.doo     # 单位
├── war3map.doo          # 装饰物
├── war3map.w3u          # 自定义单位
├── war3map.w3a          # 自定义技能
├── war3map.wts          # 字符串表
├── war3map.j / .lua     # 脚本
└── war3map.imp          # 导入资源清单
```
