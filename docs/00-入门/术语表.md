# 术语表

War3 mod 制作常用术语中英对照。

## 游戏与地图

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| World Editor (WE) | 世界编辑器 | 官方地图编辑器 |
| Trigger Editor | 触发器编辑器 | GUI 脚本编辑界面 |
| Object Editor | 对象编辑器 | 编辑单位/技能/物品等数据 |
| Terrain Editor | 地形编辑器 | 绘制地形 |
| Campaign Editor | 战役编辑器 | 组织多张地图 |
| melee map | 对战地图 | 标准 RTS 规则地图 |
| custom map | 自定义地图 | 用户制作的地图 |
| creep | 野怪 | 中立敌对单位 |
| melee | 对战 | 采集建造对战的玩法 |

## 文件格式

| 扩展名 | 说明 |
| --- | --- |
| `.w3x` | 冰封王座地图（TFT） |
| `.w3m` | 混乱之治地图（ROC） |
| `.w3n` | 战役包 |
| `.w3g` | 录像（Replay） |
| `.w3v` | 游戏缓存（Game Cache，战役存档） |
| `.mpq` | Blizzard 归档容器格式 |
| `.mdx` / `.mdl` | 模型（二进制 / 文本） |
| `.blp` | Blizzard 贴图格式 |
| `.slk` | 表格数据文件（单位/技能基础数据） |
| `.fdf` | 框架定义文件（UI） |
| `.toc` | 表目录（UI 加载列表） |
| `.dds` / `.tga` | 贴图（Reforged 支持） |

## 脚本与 API

| 术语 | 说明 |
| --- | --- |
| **JASS** | War3 原生脚本语言（Just Another Scripting Syntax） |
| **vJASS** | JASS 的扩展方言，需 JNGP 编译 |
| **Lua** | Reforged 1.31+ 支持的现代脚本语言 |
| **Wurst** | 编译到 JASS 的现代语言 |
| **native** | 引擎原生函数（定义在 common.j） |
| **BJ 函数** | Blizzard.j 中的封装函数（GUI 生成） |
| **trigger** | 触发器：事件 + 条件 + 动作 |
| **event** | 事件，触发条件 |
| **condition** | 条件，布尔过滤 |
| **action** | 动作，执行代码 |
| **handle** | 游戏对象引用（可被引用的对象） |
| **agent** | 引用计数对象（handle 的子类型） |
| **widget** | 可交互游戏对象（unit/destructable/item 的父类） |
| **leak** | 内存泄漏（未销毁的 handle） |
| **desync** | 同步错误（多人游戏中各客户端状态不一致） |
| **GetLocalPlayer** | 获取本地玩家，用于仅本地可见的效果 |
| **hashtable** | 哈希表（1.24+ 的数据存储） |
| **gamecache** | 游戏缓存（战役间传递数据） |
| **FourCC** | 四字符码，对象 ID 的表示（如 `'hfoo'` = 步兵） |

## 对象数据类型

| 文件 | 类型 |
| --- | --- |
| `war3map.w3u` | 单位（Unit） |
| `war3map.w3t` | 物品（Item） |
| `war3map.w3a` | 技能（Ability） |
| `war3map.w3b` | 可破坏物（Destructable） |
| `war3map.w3d` | 装饰物（Doodad） |
| `war3map.w3q` | 升级（Upgrade） |
| `war3map.w3h` | 增益/魔法效果（Buff） |
| `war3mapSkin.w3b` | 皮肤版可破坏物 |

## 常见对象 ID 前缀

| 前缀 | 类型 |
| --- | --- |
| `h` | Human（人族） |
| `o` | Orc（兽族） |
| `u` | Undead（不死族） |
| `e` | Night Elf（暗夜精灵） |
| `n` | Neutral（中立） |
| `A` | Ability（技能） |
| `B` | Buff（增益） |
| `R` | Upgrade（升级） |
| `I` | Item（物品） |
| `D` | Destructable / Doodad |
| `T` | 建筑（Building） |

## 常用缩写

| 缩写 | 全称 | 说明 |
| --- | --- | --- |
| WE | World Editor | 世界编辑器 |
| GUI | Graphical User Interface | 触发器图形界面 |
| BJ | Blizzard.j | 官方封装函数库 |
| JNGP | Jass NewGen Pack | 经典版扩展编辑器 |
| MPQ | Mo'PaQ | Blizzard 归档格式 |
| CASC | Content Addressable Storage Container | 新版存储格式 |
| TFT | The Frozen Throne | 冰封王座 |
| ROC | Reign of Chaos | 混乱之治 |
| DotA | Defense of the Ancients | 著名自定义地图 |
| MOBA | Multiplayer Online Battle Arena | 多人在线竞技 |
| FPS | Frames Per Second | 帧率 |
| API | Application Programming Interface | 应用编程接口 |
| AI | Artificial Intelligence | 人工智能（此处指电脑玩家） |
