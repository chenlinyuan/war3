# 单位系统（给玩家添加/删除单位）

在任意 War3 地图中通过聊天命令**搜索单位**、**创建单位给玩家**、**删除单位**。

## 命令

| 命令 | 说明 |
| --- | --- |
| `listunit <关键词>` | 搜索单位名或护甲类型（如 `listunit 圣` 或 `listunit divine`，最多 30 条） |
| `addunit <名称>` | 在**选中单位的位置**创建一个该单位，归属玩家 |
| `addunit <单位ID>` | 按 ID 创建（区分同名，如 `addunit hfoo`） |
| `removeunit` | 删除**当前选中的单位** |
| `removeunit <名称>` | 删除玩家拥有的所有该名称/ID 的单位 |

## 使用示例

```
listunit 恶魔        → 列出所有名称含"恶魔"的单位
listunit hero        → 列出所有英雄（护甲类型 hero）
addunit 步兵         → 在选中位置创建"步兵"，归属自己
addunit hfoo        → 按 ID 创建
removeunit          → 删除当前选中的单位
removeunit 步兵      → 删除自己拥有的所有"步兵"
```

## 工作原理

单位 **ID + 名称 + 护甲类型** 在**注入时预先扫描并硬编码**到脚本中：

- **进游戏立即可用**（无需枚举）
- 搜索匹配**预扫描的名称或护甲类型**
- 数量大时分帧填充（`IB_UnitFillStep`），避免单帧操作数超限

### 数据来源

- **官方地图（如 Lost Temple）**：`tools/war3map-injector/collect_game_units.py`
  1. 游戏 `unitdata.slk`（X1 = 单位 ID）
  2. 游戏 `unitbalance.slk`（X34 = 护甲类型 defType）
  3. 游戏各 races `unitstrings.txt`（单位名）
- **自定义地图**：`tools/war3map-injector/collect_units.py`
  1. 地图 `units/unitbalance.slk`（护甲类型）
  2. 地图 `units/campaignunitfunc.txt` / `unitfunc.txt`（单位名）

### 生成流程

```powershell
# 官方地图（用游戏标准单位）
python tools/war3map-injector/collect_game_units.py

# 或自定义地图（用地图解包目录）
python tools/war3map-injector/collect_units.py "maps/你的地图"

python tools/war3map-injector/build_fj.py
python tools/war3map-injector/inject_map.py "maps/你的地图.w3x"
```

## 护甲类型

| armor 值 | 说明 |
| --- | --- |
| `hero` | 英雄 |
| `large` | 重型护甲 |
| `medium` | 中型护甲 |
| `small` | 轻型护甲 |
| `fort` | 城甲 |
| `none` | 无护甲 |
| `divine` | 神圣护甲 |

## 实现位置

| 文件 | 内容 |
| --- | --- |
| `scripts/item-browser/g.j` | 单位全局变量（`ib_unitList` / `ib_unitName` / `ib_unitArmor` 等） |
| `scripts/item-browser/f.j` | `IB_UnitSearch` / `IB_AddUnit` / `IB_RemoveUnit` 等 |
| `tools/war3map-injector/build_fj.py` | 生成 `IB_UnitFillN` / `IB_UnitFillStep` 并在 `IB_Init` 中启动 |

## 已知限制

- **创建位置**：`addunit` 在选中单位的位置创建；若未选中单位会提示。
- **可创建性**：部分单位（如某些建筑/特殊单位）可能无法通过 `CreateUnit` 创建，会提示失败。
- **删除范围**：`removeunit <名称>` 只删除**自己拥有**的单位（不删其他玩家/中立单位）。
- **多人同步**：填充使用同步计时器，不会 desync；命令只对输入者生效。
