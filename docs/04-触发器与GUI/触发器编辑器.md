# 触发器编辑器

> World Editor 的图形化脚本系统

## 1. 界面结构

```
触发器编辑器 (F4)
├── 左栏：触发器树（分类 / 触发器）
├── 中栏：事件 / 条件 / 动作
└── 右栏：参数编辑
```

## 2. 创建触发器

1. 右键触发器树 → **新建触发器**。
2. 右键触发器 → **新建事件**。
3. 右键触发器 → **新建条件**（可选）。
4. 右键触发器 → **新建动作**。

## 4. 条件类型

| 分类 | 示例 |
| --- | --- |
| 布尔比较 | (触发单位) 是 英雄 等于 真 |

| 实数比较 | (触发单位) 的魔法值 小于 50.0 |

| 玩家比较 | (触发玩家) 等于 玩家 1 |
| 布尔表达式 | And / Or / Not |

## 6. 变量

**Ctrl + B** 打开变量编辑器。

| 类型 | 说明 |
| --- | --- |
| 整数 | integer |
| 实数 | real |
| 布尔 | boolean |
| 字符串 | string |
| 单位 | unit |
| 单位组 | group |
| 点 | location |
| 区域 | region |
| 触发器 | trigger |
| 计时器 | timer |
| 对话框 | dialog |
| 玩家 | player |
| 玩家组 | force |
| 物品 | item |
| 特效 | effect |
| 哈希表 | hashtable |

变量支持**数组**（勾选「数组」）。GUI 变量在 JASS 中会生成 `udg_变量名` 全局变量。

## 7. 自定义脚本

在动作中添加「自定义脚本代码」，可直接写 JASS：

```jass
call BJDebugMsg("Hello from custom script")
```

> GUI 与自定义脚本混用时，注意变量命名（`udg_` 前缀）。

## 8. 常用触发器模式

### 8.1 计时器循环

```
事件: 时间 - 每 1.00 秒游戏时间
条件: (无)
动作: 
  - 设置 游戏时间变量 = 游戏时间变量 + 1
  - 如果 游戏时间变量 >= 60 则
    - 显示文本 "一分钟过去了！"
```

### 8.2 单位进入区域

```
事件: 单位 - 一个单位进入 区域001
条件: (进入单位) 是 英雄 等于 真
动作: 游戏 - 显示文本给 (所有玩家): "英雄进入了区域！"
```

### 8.3 技能施放

```
事件: 单位 - 一个单位施放技能
条件: (施放技能) 等于 风暴之锤
动作: 
  - 单位 - 杀死 (技能目标单位)
  - 特效 - 在 (技能目标点) 创建特效
```

### 8.4 对话框

```
事件: 对话框 - 对话框按钮被点击
条件: (被点击的按钮) 等于 按钮001
动作: 游戏 - 显示文本给 (所有玩家): "你点击了按钮 1"
```

## 9. 触发器转 JASS

GUI 触发器保存在 `war3map.wtg`（二进制），编译后的 JASS 在 `war3map.j`。

World Editor 可导出脚本：**文件 → 导出脚本**。
