# ALAS 离线改图工具

## 开发与验证约束

代理不得主动启动、截图、点击、输入或操作 Warcraft III、World Editor
或其他游戏/编辑器 GUI 进程，也不得使用 `-loadfile` 做代理自行实机测试。
静态检查、构建、pjass、归档校验、哈希和 Map Doctor 照常执行；需要实机
验证时，应给出准确测试步骤和预期现象，由用户运行并反馈结果。

基础攻击有 1% 概率永久增加 1 点敏捷，不设成长上限。
成长通过 Reforged 伤害事件识别真实基础攻击，避免被同物品的顺劈
攻击修饰器覆盖；概率定义在 `tools/war3map-injector/add_warglaive_lt30.py`，
正式发布前可统一改回 1%。冲锋特效使用的 `StormfallRed.mdx` 构建副本
会移除 `EVTS` 音效事件，只保留视觉；命中特效
`DemonBoltImpact` 也构建为去音效副本
`war3campImported\DemonBoltImpactSilent.mdx`，避免逐个敌人播放雷击声。
战役构建会同时把这些去音效资源写入战役外层；审计只匹配模型文件名，
避免 JASS 双反斜杠转义造成误报。

AI 图标生成不参与运行；图标、模型、武器、四翼和本地物品目录均随工具打包。

## 使用

双击发行目录中的 `ALAS-Offline.exe`：

1. 选择未注入 ALAS 的 `.w3n` 战役或 `.w3x/.w3m` 地图。
2. 工具自动识别脚本类型和已有 ALAS 模块。
3. 成品扩展名跟随源文件；战役默认保存到
   `Documents\Warcraft III\Campaigns`。
4. 点击“开始构建”。工具完成注入、目录审计、结构审计、规则审计和
   可选 Map Doctor 检查。

“自动修复存档”默认开启。构建成功后会查找与成品同名的存档目录，以便把
旧存档绑定到本次生成的地图身份。修复前工具会创建
`save-repair-backup-时间` 备份；找不到同名存档目录时会跳过，不会阻止
成品生成。

### 无损压缩

“无损压缩”默认开启，替代原来的“紧凑归档”选项：

- 战役：逐章重新压缩 MPQ 扇区、去重章内完全相同数据、清除未引用空洞；
- 单图：重新压缩并去重地图内部数据；
- 图片不做 BLP 重编码，所有内部文件在战役缩容前后逐字节校验；
- 章节仍以游戏要求的未压缩条目存放在外层战役中。

关闭后会保留旧数据布局以确保最大兼容性，代价是文件明显更大。
如果缩容器无法证明章节逐文件内容不变，工具会保留已通过注入读回校验的
未缩容成品并继续审计；地图仍可使用，代价是文件更大，不会因此中止整个战役。

### 被遗忘的王国专用处理

工具通过完整章节列表自动识别《被遗忘的王国》Lua 战役，并额外执行：

1. 修复 `war3map.wct` 中多算 1 字节的文本长度；
2. 修复鼠巢、坑道、巢母、黑暗犬和女妖任务逻辑；
3. 在 ALAS 构建后执行战役级无损压缩；
4. 审计 WCT/WTG 配对和任务修复标记。

该流程只对识别出的被遗忘的王国战役生效；其他地图仍可使用通用无损压缩。

### 画面模式跟随游戏设置

“画面模式跟随游戏设置”默认关闭。开启后会把新版地图的
`supported_modes` 设为 `SD | HD`，允许经典和 Reforged 两套画面，
实际使用哪一套由游戏设置决定。旧版地图没有该字段，本来就不限制画面
模式，因此会保持原样。

旧版自定义战役常把标准英雄模型写进 skin 对象数据。此时只改
`supported_modes` 不会生效，因为 `war3campaignSkin.w3u` /
`war3mapSkin.w3u` 仍会指定经典模型。本选项会同时移除这些标准英雄的
`umdl`（本体）与 `upor`（头像）覆盖，让游戏在 SD 下使用经典模型、在 HD
下使用 Reforged 模型。普通单位与自定义装饰模型不会被清掉。

所有完整 ALAS 成品都会自动应用统一装备规则，包括装备不可出售、群体传送
使用澄海 3C 的 `AImt` 配置、埃辛诺斯战刃冲锋快捷键为 `C`。

## 离线边界

- 不访问网络、不上传地图、不调用在线 AI。
- 首次移植仍需要用户自己的干净源战役或地图。
- 自动存档修复要求 `node` 位于 `PATH` 中；缺少 Node.js 时会保留成品，
  并在完成提示中报告存档修复失败。
- 当前 ALAS 运行时依赖 Reforged 3.0。
- 游戏图标与完整物品/技能目录都有本地快照；没有安装游戏时仍可构建，
  但实际游玩仍需要用户自己的 Warcraft III。
- 不随工具分发用户战役、地图或暴雪地图内容。
- 加密、壳化而无法读取脚本的地图会在预检查或构建阶段停止。
