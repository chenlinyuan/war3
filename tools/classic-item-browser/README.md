# ALAS 经典版物品浏览器

这是一个独立的经典版 1.27 改图工具，只注入物品搜索与添加功能。

## 功能

- 从 1.27 基础物品目录和地图 `Units\ItemFunc.txt` 合并物品；
- 保留地图原对象数据，只替换 `war3map.j` 和地图标题；
- 不注入 `Blz*` API、四翼、神器、新背包、装备栏、天赋或单位命令；
- 使用经典版 JASS 基线运行 pjass 和归档校验。

## 游戏内命令

```text
itembrowser
search <关键词>
search <关键词> <页码>
additem <物品名> [数量]
additem <物品ID>
```

搜索结果每页原版和自定义各最多 15 条，并提示下一页命令。

## 边界

- 只支持单张 JASS `.w3x` / `.w3m` 地图；
- 不支持 `.w3n` 战役、Lua 地图或 Reforged 专属功能；
- 大体积地图仍需要支持大图上限的经典版客户端或加载器；
- 静态编译和归档检查不能证明游戏内聊天事件一定注册成功，仍需用户实机验证。
