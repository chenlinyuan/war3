## 模板分类

| 类别 | 说明 |
| --- | --- |
| 初始化 | 地图初始化、库初始化 |
| 触发器 | 事件注册、条件过滤 |
| 单位 | 创建、属性、技能 |
| 计时器 | 循环、延迟 |
| 投射物 | 弹道系统 |
| 伤害 | 伤害检测、修改 |
| 存档 | 存档/读档 |
| UI | 多面板、对话框、框架 |
| 工具 | 数学、字符串、单位组 |

## 使用说明

- 模板为起点，按需修改。
- 注意内存泄漏与 desync。
- 生产环境建议封装为库。
