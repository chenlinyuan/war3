# 血色使命：杰雷护身符恢复机制

## 结论

恢复效果功能上属于杰雷的护身符，但实现不是物品自带主动技能。

- 护身符物品：`I625`。
- 恢复触发技能：`A66M`（基于 `ANcl`，命令 `divineshield`）。
- 临时恢复能力：`A651`，脚本附加后隐藏。
- `I625.iabi` 为空，`icid` 也未配置；不能靠点击物品栏直接施法。
- 多个杰雷单位版本的 `uabi` 直接包含 `A66M`，因此章节切换后能力仍随角色单位数据存在。

## 触发流程

1. 任意单位受伤事件检查触发单位：

   ```jass
   GetUnitAbilityLevel(GetTriggerUnit(), 'A66M') > 0
   and GetUnitLifePercent(GetTriggerUnit()) <= 20.00
   ```

2. 满足时立即下达 `divineshield`（即时命令 ID `852090`）。
3. `SPELL_EFFECT` 检测到 `A66M` 后：
   - 清除单位身上可驱散/负面 buff；
   - 临时添加并隐藏 `A651`；
   - 添加胸部恢复特效，持续 10 秒；
   - 向玩家显示提示。
4. 10 秒内启用周期触发器，每 0.1 秒增加 4 点生命，总计约 400 点。
5. 10 秒结束时移除 `A651`、关闭周期触发器并清理 hashtable。

## 可借鉴与不可误解的部分

- 可借鉴：技能触发前再次检查持有者与生命阈值；临时增益有明确添加、隐藏、结束和清理路径。
- 可借鉴：进入章节时不重新构造整套技能对象，而是让稳定能力存在于角色单位数据中。
- 不可误解：护身符没有使用骑士标枪的 `iabi/icid` 模式；它靠自定义单位 `uabi` 和脚本触发器工作。
- 对通用离线改图，未知英雄单位类型很多，不能把神器主动技能硬写进所有单位数据。仍有明确 `iabi/icid` 支持的章节应优先使用物品所有权；旧数据章节再用命令栏技能加加载后自动同步。

## 相关对象

| 对象 | 用途 |
| --- | --- |
| `I625` | 护身符物品，无 `iabi`，不可掉落、不可出售 |
| `A66M` | 杰雷护身符的命令栏触发技能 |
| `A651` | 10 秒内隐藏的临时恢复能力 |
| `A674` | 独立的生命恢复速度被动 |
