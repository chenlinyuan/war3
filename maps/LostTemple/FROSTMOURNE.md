# Lost Temple 霜之哀伤版本

成品地图：`LostTemple_heroes.w3x`

游戏内添加：

```text
additem I105
additem 霜之哀伤
additem frost
additem frostmourne
```

## 对象

| 对象 | ID | 基准 |
|---|---|---|
| 霜之哀伤 | `I105` | `gcel` |
| 冰封践踏 | `A105` | 瞬发 `ANcl`，独立命令 `froststomp` |
| 攻击速度 +50% | `A106` | `AIsx` |
| 霜冻攻击 | `A107` | `AIob` |
| 攻击力 +30 | `A108` | `AIat` |
| 魔法恢复 +2 倍 | `A109` | `AIrm` |

物品只保留被动 `A106,A108,A109`。主动冰封践踏 `A105` 作为英雄
技能栏技能，装备时添加、卸下时移除，快捷键为 `D`。`A107` 不再挂到物品上；普通攻击通过
30% 概率的霜冻新星提供范围伤害与减速。

## 数值

- 攻击速度 +50%
- 攻击力 +30
- 魔法恢复 +2 倍（`Imrp=2.0`，即 +200%）
- 普通攻击有 30% 概率触发 250 范围霜冻新星
- 霜冻新星主目标额外受到 50 点伤害，并减速 4 秒
- 霜冻新星（绿色，攻击触发）→ 噬魂（绿色，击杀触发）
  → 冰封践踏入口（浅蓝色）→ 剧情（金黄色）
- 物品说明只保留“装备后获得技能”入口；完整效果写在技能栏说明中
- 耗魔 100、冷却 10 秒已由技能按钮显示，不在技能说明中重复
- 主动伤害 `100 + 力量 × 4`
- 普通单位冰冻 5 秒，英雄冰冻 3 秒
- 魔法免疫单位会被冻结，但不受到伤害
- 噬魂：击杀有效普通敌人有 5% 概率永久增加 1 点力量，
  击杀英雄有 50% 概率
- 召唤物、幻象、建筑、机械与中立被动单位不提供灵魂
- 噬魂成功时在持有者头顶显示紫色“霜之哀伤·噬魂：力量 +1”
- 空中单位和建筑的冻结使用每个目标独立的计时器，避免失效句柄导致永久暂停
- 当前测试版恢复为 `idro=1`，可丢弃以检查地面剑模型
- `ipaw=0`，不可出售或典当

## 表现

- 物品图标：`BTNFrostMourne.blp`
- 主动冰爆：仅由脚本创建一次 `war3campImported\IceStompRaised.mdx`；
  `A105.acat` 为空，避免引擎重复播放
- 地面、空中单位和建筑冻结统一使用
  `Abilities\Spells\Undead\FreezingBreath\FreezingBreathTargetArt.mdl`
  半透明目标模型；单位和建筑都附着 `origin`
- 每座建筑只创建一个特效，延长时间不重复叠加，解冻时销毁
- 无敌目标（包括金卡、生命之泉等无敌中立建筑）通过
  `BlzIsUnitInvulnerable` 与 `Avul` 检查排除，不会受到伤害或冻结
- 技能在施法开始事件立即结算，没有脚本额外等待时间
- 冰封践踏使用瞬发 `ANcl`，`aord` 与 `Ncl6` 都为 `froststomp`
- 只监听 `SPELL_CAST`/`SPELL_EFFECT`，耗蓝与冷却由引擎管理
- 不再额外拦截 `froststomp`，避免 `stop` 清冷却和防重锁互相打架
- 阿克蒙德之手、霜之哀伤、埃辛诺斯战刃对同一英雄互斥；`additem`
  在入包前直接拦截，其他拾取来源则在 0.05 秒后把新物品放到英雄前方
- 施法路径不会临时禁用 `A105`；每次物品同步都会强制重新启用，
  避免动作链中断后技能永久不可用
- 若自定义 order 未触发，则由 `SPELL_CAST`/`SPELL_EFFECT` 兜底，
  并用 9.5 秒防重锁避免同一冷却周期内重复结算
- `aani=stand`，叠加显式 `SetUnitAnimation(caster, "stand")`
- 脚本造成完整的 `100 + 力量 × 4`，普通单位冻结 5 秒、英雄 3 秒
- 冻结使用 `Bfrz` 同款 `FreezingBreathTargetArt.mdl` 冰块模型
- 脚本按需求等待 `0.05` 秒后开始范围扫描
- 英雄复活结束时重新同步装备技能
- 掉落物：无底座的独立霜之哀伤模型
- 地面光环：`war3campImported\Rune-Blue-Aura_Raised20.mdx`
- 每件地面霜之哀伤拥有独立光环
- 拾取时立即销毁对应光环

本版不添加英雄持有剑模型，避免与剑圣原有武器重叠。
