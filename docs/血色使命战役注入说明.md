# 血色使命 I 十周年纪念版 — 战役注入说明

> 目标：为战役地图 `血色使命 I 十周年纪念版.w3n` 添加**物品浏览器**、**技能系统**与**阿克蒙德之手**。

## 结果

- 原文件：`H:\Games\War3\Campaigns\血色使命 I 十周年纪念版.w3n`（53,797,549 字节）
- 注入后：67,540,763 字节（+13,743,214）
- 备份：`血色使命 I 十周年纪念版.w3n.bak`（原始文件）

## 战役结构

`.w3n` 是战役归档（HM3W 头 + MPQ），包含：

- **19 张章节地图**：`prologue.w3x`、`chapter1-10.w3x`、`chapter7-2/9-2/9-3/10-2.w3x`、`incident*.w3x`、`end.w3x`
- **战役共享数据**：`war3campaign.w3a`（技能）、`war3campaign.w3t`（物品）、`war3campaign.w3u`（单位）、`war3campaign.w3h`（buff）、`war3campaign.wts`（字符串）

## 注入内容

### 1. 战役级共享数据（一次注入，所有章节生效）

- `war3campaign.w3t`：追加 **I000 阿克蒙德之手**（+50% 攻击力光环 + 100% 攻速 + 死亡之指主动技）
- `war3campaign.w3a`：追加 **A000 死亡之指**、**A001 阿克蒙德之力**（AIar 强击光环）、**A002 攻击速度加成**（AIsx）、**Azcr 致命一击**
- 保留战役原有的 124 条 orig + 249 条 custom 技能、104 条 orig + 128 条 custom 物品

### 2. 脚本（逐章节注入）

每张章节地图的 `war3map.j` 追加物品浏览器 + 技能系统脚本：

- 物品：**402 件**（273 游戏标准 + 128 战役自定义 + I000）
- 技能：**912 个**（817 游戏 + 95 战役自定义）

**可用命令**（游戏内聊天输入）：

| 命令 | 说明 |
|------|------|
| `additem <名称或ID>` | 添加物品（如 `additem 阿克蒙德之手` 或 `additem I000`） |
| `search <关键词>` | 搜索物品（原版/自定义分开显示） |
| `itembrowser` | 显示帮助 |
| `addskill <名称或ID> [等级]` | 添加技能 |
| `removeskill <名称或ID>` | 移除技能 |
| `listskill [关键词]` | 列出技能 |

## 关键技术问题与解决

### 问题 1：战役保护

`.w3n` 的 MPQ 哈希/块表用**自定义密钥加密**（`war3mpq.py list` 返回 0 文件）。
**解决**：HKE（HkeW3mModifier2.0）自带 MPQ 读取器，可直接打开并「分析文件」→「全部解压」。

### 问题 2：HKE 注入脚本重复 15 次（CRITICAL）

章节地图的 `war3map.j` 含 **14 个 YDWE 的 `//endglobals from XXX` 注释**。
HKE 的「注入脚本」按 `endglobals` 子串匹配，**每个出现处都插入一次 f.j** → 15 份副本，
脚本从 156KB 膨胀到 5.89MB，编译失败。

**解决**：`tools/war3map-injector/inject_script_manual.py`
自己组装脚本（g.j 插到 `endglobals` 前、f.j 插到真正的 `endglobals` 行后、`call IB_Init()` 插到 main 开头），
再用 HKE「添加/替换文件」写回。验证：每张图恰好 1 个 `IB_Init` 定义 + 1 个 `call IB_Init()`。

### 问题 3：globals 常量顺序

章节 globals 块以 `constant boolean LIBRARY_YDWE...` 开头。
我们的非 constant 变量必须放在所有 constant 之后（`endglobals` 之前）。
`inject_script_manual.py` 已正确处理。

### 问题 4：merge_w3obj 会丢失 orig 条目

`merge_w3obj.py` 把 orig 条目转成 custom（origCount=0）。
战役有 124 条 orig（对标准技能的覆盖），必须保留。
**解决**：新增 `tools/war3map-injector/append_w3obj.py`，保留目标的 origCount，只追加新 custom 条目。

## 复现步骤

```powershell
# 1. 解压战役（HKE 打开 .w3n → 分析文件 → 全部解压）
#    输出到 H:\Games\War3\Campaigns\血色使命 I 十周年纪念版\

# 2. 收集物品/技能
python tools/war3map-injector/collect_items.py "H:\Games\War3\Campaigns\血色使命 I 十周年纪念版\prologue"
python tools/war3map-injector/_collect_campaign_items.py "H:\Games\War3\Campaigns\血色使命 I 十周年纪念版"
python tools/war3map-injector/collect_skills.py "H:\Games\War3\Campaigns\血色使命 I 十周年纪念版\prologue"
# (再合并 war3campaign.w3a 技能)

# 3. 生成 f.j
python tools/war3map-injector/build_fj.py
python tools/war3map-injector/validate_dir.py scripts/item-browser

# 4. 战役级数据（阿克蒙德之手）
python tools/war3map-injector/append_w3obj.py "<camp>\war3campaign.w3a" tools/war3map-injector/_lt_hand.w3a tools/war3map-injector/_camp_hand.w3a
python tools/war3map-injector/append_w3obj.py "<camp>\war3campaign.w3t" tools/war3map-injector/_hand.w3t tools/war3map-injector/_camp_hand.w3t
python tools/war3map-injector/inject_file.py "<camp>.w3n" tools/war3map-injector/_camp_hand.w3a war3campaign.w3a
python tools/war3map-injector/inject_file.py "<camp>.w3n" tools/war3map-injector/_camp_hand.w3t war3campaign.w3t

# 5. 逐章节注入脚本
python tools/war3map-injector/inject_campaign_chapters.py "H:\Games\War3\Campaigns\血色使命 I 十周年纪念版"

# 6. 把修改后的章节替换回战役
python tools/war3map-injector/replace_campaign_chapters.py "<camp>.w3n" "maps/campaign"
```

## 相关工具
