# 游戏自带图标（存在性已用 MPQ 逐个验证过）

这些名字**确实存在于游戏里**，直接写进物品的 `iico` 就能用。
之所以没放预览图：游戏 MPQ 里的图标提取工具链目前只能完整解出少数几个
（见 `tools/war3map-injector/extract_icon.py` 的说明），预览会缺一大块。
**想看真实效果**：用 World Editor 打开地图 → 物品编辑器 → 找任一物品的「图标 - 普通」字段 → 双击选图标，左侧列表里按名字找（或直接搜索名字）。

| `BTNGauntletsOfOgrePower` | 同上，另一张手套图标 |
| `BTNClawsOfAttack` | 攻击之爪（标准爪子图标） |
| `BTNGrabTree` | 抓住一棵树（一只手） |
| `BTNNatureTouchGrow` | 自然之触（手+绿光） |

| `BTNRingSkull` | 骷髅指环 |
| `BTNSacrificialSkull` | 献祭骷髅 |
