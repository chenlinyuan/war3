# 技能数据

技能（Ability）是 War3 玩法的核心。本文档详解技能对象数据与技能系统。

## 1. 技能类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 单位技能 | 普通单位技能 | 治疗、驱散 |
| 英雄技能 | 英雄可学习技能 | 风暴之锤、暴风雪 |
| 物品技能 | 物品携带的技能 | 治疗药水、传送 |
| 自动施放 | 自动触发技能 | 治疗、驱散 |
| 光环 | 范围持续效果 | 命令光环、耐久光环 |
| 变身 | 改变单位形态 | 恶魔变身、熊形态 |

## 6. 脚本中操作技能

### 6.1 单位技能

```lua
-- 添加/移除技能
UnitAddAbility(u, FourCC("AHhb"))
UnitRemoveAbility(u, FourCC("AHhb"))

-- 技能等级
local level = GetUnitAbilityLevel(u, FourCC("AHhb"))
SetUnitAbilityLevel(u, FourCC("AHhb"), 2)
IncUnitAbilityLevel(u, FourCC("AHhb"))
DecUnitAbilityLevel(u, FourCC("AHhb"))

-- 英雄学习技能
SelectHeroSkill(hero, FourCC("AHhb"))
```

### 6.2 运行时修改技能字段

```lua
-- 获取单位技能实例
local abil = BlzGetUnitAbility(u, FourCC("AHhb"))

-- 修改技能字段
BlzSetAbilityRealLevelField(abil, ABILITY_RLF_DAMAGE_HBZ2, 0, 200.0)
BlzSetAbilityIntegerLevelField(abil, ABILITY_ILF_MANA_COST, 0, 50)
BlzSetAbilityStringLevelField(abil, ABILITY_SLF_TOOLTIP_NORMAL, 0, "新提示")

-- 修改冷却/魔法消耗
BlzSetUnitAbilityCooldown(u, FourCC("AHhb"), 1, 5.0)
BlzSetUnitAbilityManaCost(u, FourCC("AHhb"), 1, 30)
```

### 6.3 技能事件

```lua
-- 技能施放事件
local t = CreateTrigger()
TriggerRegisterAnyUnitEventBJ(t, EVENT_PLAYER_UNIT_SPELL_EFFECT)
TriggerAddAction(t, function()
    local caster = GetTriggerUnit()
    local abilId = GetSpellAbilityId()
    local target = GetSpellTargetUnit()
    local x = GetSpellTargetX()
    local y = GetSpellTargetY()

    if abilId == FourCC("AHhb") then
        -- 自定义逻辑
    end
end)
```

### 6.4 技能事件类型

| 事件 | 说明 |
| --- | --- |
| `EVENT_PLAYER_UNIT_SPELL_CAST` | 开始施放 |
| `EVENT_PLAYER_UNIT_SPELL_CHANNEL` | 开始引导 |
| `EVENT_PLAYER_UNIT_SPELL_EFFECT` | 效果生效 |
| `EVENT_PLAYER_UNIT_SPELL_FINISH` | 施放完成 |
| `EVENT_PLAYER_UNIT_SPELL_ENDCAST` | 施放结束 |

## 7. 技能系统设计模式

### 7.1 触发器增强技能（Triggered Spells）

用「假技能」（如 `Adef` 无效果技能）作为按钮，用触发器实现真实效果：

```
1. 创建基于 Adef（无目标）或 Aneu（无效果）的假技能
2. 注册 EVENT_PLAYER_UNIT_SPELL_EFFECT
3. 检测技能 ID，执行自定义逻辑
4. 用计时器/循环实现投射物、持续伤害等
```

### 7.2 假技能基类推荐

| 基类 ID | 说明 |
| --- | --- |
| `Adef` | 无效果（可自动施放） |
| `Aneu` | 无效果（不可自动施放） |
| `Aatk` | 无效果（攻击） |
| `Amov` | 无效果（移动） |

### 7.3 投射物系统

-- 简易投射物
local function createProjectile(caster, target, model, speed, onHit)

## 8. 增益（Buff）

技能效果通常关联一个**增益**（Buff），存储在 `war3map.w3h`：

| 字段 | 字段 ID | 说明 |
| --- | --- | --- |
| Name | `fnam` | 增益名称 |
| Tooltip | `ftip` | 提示 |
| Icon | `fart` | 图标 |
| Effect Art | `feat` | 效果模型 |
| Special Art | `fsat` | 特殊模型 |
| Target Art | `ftat` | 目标模型 |
| Buff Type | `fbty` | 增益类型（魔法/物理） |

### 增益类型

| 值 | 说明 |
| --- | --- |
| 0 | 无 |
| 1 | 增益（正面） |
| 2 | 减益（负面） |
| 3 | 魔法 |
| 4 | 物理 |
