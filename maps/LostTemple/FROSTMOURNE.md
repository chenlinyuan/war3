# Lost Temple 霜之哀伤版本

成品地图：`LostTemple_heroes.w3x`

游戏内添加：

```text
additem I105
additem 霜之哀伤
additem frost
additem frostmourne
```

## 对象

| 对象 | ID | 基准 |
|---|---|---|
| 霜之哀伤 | `I105` | `gcel` |
| 冰封践踏 | `A105` | `AOws` |
| 攻击速度 +50% | `A106` | `AIsx` |
| 霜冻攻击 | `A107` | `AIob` |
| 攻击力 +30 | `A108` | `AIat` |
| 魔法恢复 +2 倍 | `A109` | `AIrm` |
| 灵魂负担 | `A130`–`A141` | `AIl2` |

物品技能栏最多只能挂 4 条技能，因此最终装配为
`A105,A106,A108,A109`。`A107` 霜冻攻击不再挂到物品上，它的额外伤害为 0，
攻击减速由脚本独立处理。

## 数值

- 攻击速度 +50%
- 攻击力 +30
- 魔法恢复 +2 倍（`Imrp=2.0`，即 +200%）
- 普通攻击不附加额外冰霜伤害；攻击减速由脚本处理
- 普通单位移速降低 65%，持续 4 秒
- 英雄移速降低 65%，持续 2 秒
- 主动技能耗魔 100、冷却 10 秒、范围 550，地面、空中与建筑均有效
- 主动伤害 `100 + 最高属性 × 4`
- 普通单位冰冻 5 秒，英雄冰冻 3 秒
- 每次成功释放主动技能有 25% 概率触发灵魂吞噬
- 每次吞噬永久降低 50 点最大生命，不设常规累计上限
- 最大生命最低保留 1 点，死亡、复活或重新装备都不会恢复
- 触发时在佩戴者头顶显示紫色悬浮文字
- 灵魂负担使用 12 个独立能力按二进制组合，覆盖 4095 次触发
- 空中单位和建筑的冻结使用每个目标独立的计时器，避免失效句柄导致永久暂停
- 当前测试版恢复为 `idro=1`，可丢弃以检查地面剑模型
- `ipaw=0`，不可出售或典当

## 表现

- 物品图标：`BTNFrostMourne.blp`
- 主动冰爆：`war3campImported\IceStompRaised.mdx`
- 掉落物：无底座的独立霜之哀伤模型
- 地面光环：`war3campImported\Rune-Blue-Aura_Raised20.mdx`
- 每件地面霜之哀伤拥有独立光环
- 拾取时立即销毁对应光环

本版不添加英雄持有剑模型，避免与剑圣原有武器重叠。
